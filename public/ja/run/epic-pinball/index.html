Epic Pinball をオンラインでプレイ — シェアウェア版テーブル 動作します — シェアウェア版のテーブルがブラウザ内の DOSBox で動きます

最終更新 2026年11月 · 実行環境 DOSBox + WebAssembly

Epic Pinball は、James Schmalz が開発し Epic MegaGames が発売した 1993年のピンボールゲームです。なめらかにスクロールするテーブル、デジタル音源の音楽、そしてちゃんと重さを感じるボールが特徴です。「Android」テーブルを収録した公式のシェアウェア版をここで配信しています。プレイを押せば、ブラウザの中で起動します。

DOSBox と WebAssembly でブラウザ内で動作します。ファイルは一切アップロードされません。画面をクリックすると操作できます。マウスを解放するには Ctrl+F10 を押してください。

動作の仕組みと動作の目安

オリジナルの DOS 用シェアウェア版パッケージを、WebAssembly 版の DOSBox の中で動かしています。1 MB を大きく下回るサイズなので、ほぼ一瞬で読み込まれます。最初に Epic のイントロとメニューが表示されるので、Enter を押してテーブルへ進んでください。

Epic Pinball は 386 向けにアセンブリ言語で書かれており、Chromebook を含め、ほとんどどんな端末のブラウザでもフルスピードで動きます。

遊び方

左右の Shift キーがフリッパーです。下矢印キーを押し続けるとプランジャーが引かれ、離すと発射します。Space で台を揺らせますが、やりすぎるとティルトになります。ゲーム内のヘルプ画面にすべてのキーが載っています。

「Android」テーブルでまず覚えたいのは、ロボットのパーツをひとつずつ完成させていくランプショットです。アンドロイドを完成させると、大きな得点が動きはじめます。

シェアウェア版と製品版について

これは Epic MegaGames が無償配布用に出したシェアウェア版で、VENDOR.DOC と LICENSE.DOC が同梱されています。製品版のパックではテーブルが追加されましたが、それらは商用製品のため、ここでは配信していません。

よくある質問

ここの Epic Pinball は無料で遊べますか？

はい。これは公式のシェアウェア版で、Epic MegaGames が無償配布用に公開したものです。製品版のテーブルパックは配信していません。

どのテーブルが収録されていますか？

シェアウェア版のテーブル「Android」です。ほかのテーブルは製品版のパックで販売されていました。

操作方法は？

左右の Shift がフリッパー、下矢印キーでプランジャーを引き、Space で台を揺らします。

これは Windows に付いていたピンボールですか？

いいえ。Windows に付属していたピンボールは 3D Pinball: Space Cadet です。このサイトには、そのエンジン向けのオープンなテーブルが別のページにあります。Epic Pinball はそれより前に別のスタジオが作った DOS ゲームです。

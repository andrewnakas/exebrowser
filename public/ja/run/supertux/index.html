SuperTux は、ペンギンの Tux が主役の、無料でオープンソースの横スクロールアクションゲームです。走って、跳んで、雪玉を踏みつけ、コインを集めながら、氷の島（Icy Island）と森（Forest）を進みます。ここにあるのは、SuperTux プロジェクト自身によるバージョン 0.6.3 の公式ウェブビルドで、ゲームの全編です。ランチャーをクリックすると、このタブで開きます。

仕組みと知っておきたいこと

このゲームは SuperTux チームによる公式の WebAssembly 版で、改変せずにここで配信しています。サイズは大きめです。初めて遊ぶときにステージ、グラフィック、音楽など約 250 MB をダウンロードするので、Wi-Fi 環境で起動し、1〜2分ほどお待ちください。そのあとはブラウザがデータを保持します。

SuperTux はこのページの中ではなく、独立したページとして開きます。ゲームは複数のスレッドで動作しますが、ブラウザがそれを許可するのは、ほかのサイトから分離されたページだけです。別のページの中に埋め込まれたゲームは、その条件を満たせません。ここへ戻るには、ブラウザの「戻る」ボタンを使ってください。

WebGL と、ある程度新しいパソコンが必要です。スマートフォンやメモリの少ない Chromebook には向いていません。

遊び方

矢印キーで移動、Space でジャンプ、Ctrl でダッシュします。ファイアフラワーを取ったあとは、同じキーで火の玉も投げられます。下矢印キーでしゃがみます。キーはすべて Options → Setup Keyboard で変更できます。Start Game → Story Mode を選ぶと Icy Island から始まります。メインメニューの Level Editor もブラウザで動きます。

よくある質問

これは SuperTux の完全版ですか？

はい。SuperTux プロジェクトが公開している公式の 0.6.3 ウェブビルドで、Story Mode、ボーナスステージ、レベルエディタが含まれています。

初回の読み込みにこれほど時間がかかるのはなぜですか？

ゲームのデータが約 250 MB あるためです。ダウンロードは一度だけで、そのあとはブラウザが保持するので、次回以降はずっと速く起動します。

なぜ別のページとして開くのですか？

SuperTux は複数のスレッドを同時に使いますが、ブラウザがそれを許可するのは、ほかのサイトから分離されたページだけです。このページの中に埋め込んだゲームは分離できないため、ランチャーは単独のページとして開きます。

進行状況は保存されますか？

はい。SuperTux はセーブデータをこのブラウザに保存します。サイトのデータを消去すると、セーブデータも消えます。

DOOM をブラウザでプレイ 動作します — オリジナルの DOS 版が DOSBox で実行されます

最終更新 2026年7月 · 実行環境 DOSBox + WebAssembly

DOOM——1993年に id Software が発表し、その後のあらゆる一人称視点シューティングの原型となった作品です。第1エピソード「Knee-Deep in the Dead」はシェアウェアとして無償配布が認められており、今も合法的に無料で遊べます。

ここで動いているのは本物の DOS 版の実行ファイルです。リメイクでも JavaScript による再実装でもありません。DOSBox を WebAssembly にコンパイルして、そのままブラウザ内で走らせています。ダウンロード不要、インストール不要、アカウント登録も不要です。

動作の仕組み

1993年に出荷された DOS の実行ファイルを、WebAssembly 版の DOSBox がそのまま実行します。グラフィックも音も操作感も、当時のフロッピーディスクの中身と同じものです。

収録されているのは第1エピソード（全9面）で、id Software が自由な再配布を認めた範囲そのものです。残りのエピソードは商用版のため、ここには含まれていません。

操作方法と動作環境

移動は矢印キー、射撃は Ctrl、ドアを開けるのは Space、武器の切り替えは 1〜7 です。マウスでの視点操作にも対応しています。スマートフォンやタブレットでは、画面上にキーパッドが表示されます。

1993年のゲームなので容量も小さく、Chromebook のような非力な端末でも問題なく動きます。処理はすべてブラウザ内で完結し、サーバーには何も送信されません。

よくある質問

ダウンロードせずに無料で遊べますか？

遊べます。第1エピソードは id Software が無償配布を認めたシェアウェア版で、ブラウザ上でそのまま動作します。インストールするものはなく、アカウント登録も必要ありません。

これは本物の DOOM ですか、リメイクですか？

本物です。1993年の DOS 実行ファイルを、WebAssembly にコンパイルした DOSBox の中で動かしています。当時の PC で動いていたコードとまったく同じものです。

ここで遊ぶのは合法ですか？

合法です。掲載しているのは第1エピソードのみで、これは自由にコピーして配ってよいものとして公開されたシェアウェア版です。商用エピソードは含んでいません。

進行状況は保存されますか？

保存されます。ゲーム内のセーブ機能だけでなく、面の途中でタブを閉じても、次に開いたときに中断した場所から再開できます。データはすべてブラウザ内に保存され、どこにもアップロードされません。アカウントもないため、別の端末には引き継がれません。

スマートフォンでも動きますか？

動きます。タッチ操作の端末では画面上にゲーム用のキーパッドが表示されます。パソコンのほうが快適ですが、スマートフォンでも問題なく遊べます。

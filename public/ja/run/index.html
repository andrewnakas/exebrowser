どの実行環境が何を動かすのか

このサイトでは三つの異なる実行環境が動いており、どれを使うかで、その作品がどれだけ快適に動くかがおおよそ決まります。

DOSBox を WebAssembly にコンパイルしたものが、DOS 用のゲーム——DOOM、Wolfenstein 3D、Commander Keen など——を動かします。これがもっとも確実な方法です。当時の実行ファイルが数秒で起動し、いまのパソコンならフルスピードで動きます。Wine と x86 エミュレータの組み合わせは Windows 用のソフトを動かしますが、こちらははるかに難しい仕事です。32ビットの Win32 環境そのものをブラウザの中に組み立て直す必要があるためで、速度はネイティブのおよそ 10〜40% ほど、動くものの範囲もかなり狭くなります。ScummVM はポイント&クリック型のアドベンチャーを担当します。

このサイトのページには、遊べる作品ではなく解説記事にとどまるものもあります。ソフトが商用製品である場合、ここに置くには容量が大きすぎる場合、あるいはブラウザでは用意できないハードウェアを必要とする場合です。そうしたページには冒頭にその旨を書き、では何を使えば動くのかを説明しています。

Boxedwine・Wine・WebAssembly を利用しています。Wine は CodeWeavers の商標です。ExeBrowser は WineHQ、CodeWeavers、Microsoft とは無関係です。姉妹サイト：macemu.com（ブラウザで遊べるクラシック Mac ゲーム）。

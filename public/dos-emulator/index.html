Run your own DOS program in the browser

Runs via DOSBox on WebAssembly · Nothing is uploaded · No account

Drop a DOS game or program below — the .exe, .com or .bat, its whole folder, or a zip of it — and it runs in DOSBox inside this tab. The files are read on your own machine and put on a virtual C: drive that exists only in the tab's memory. This is the same DOSBox that runs DOOM and Commander Keen on this site.

The emulator is about 1.4 MB and cached after the first run. Click the screen to give it your keyboard. When the program exits you are left at the C:\> prompt, where you can type another command.

What runs, and what does not

This is DOSBox, the emulator most people use to play old PC games today, compiled to run in a web page. If a program runs in DOSBox on a desktop, it very likely runs here too — just slower, because every instruction is emulated in your browser.

Works well

  • DOS games from the 1980s and 1990s: real-mode games and DOS/4GW ones such as DOOM-era shooters.
  • Sound Blaster 16, AdLib music and the PC speaker, all emulated.
  • Text-mode programs: old editors, BASIC, Turbo Pascal, utilities, BBS-era tools.

Does not

  • Windows programs, including Windows 3.x. DOSBox only prints This program cannot be run in DOS mode. The page notices and offers to send the files to the Windows loader instead.
  • CD-ROM games that check for the disc, and anything needing a network, a modem or a printer.
  • Very demanding late-90s games may be too slow on a phone or an older laptop.

If it does not start

  1. Load the folder, not the lone EXE. Nearly every DOS game keeps its graphics and levels in files beside the program.
  2. Check which program starts. A folder often has SETUP.EXE, INSTALL.EXE and the game itself; the page guesses the game, but the picker lets you choose.
  3. Run the setup program first, if the game has one. Many games need a configuration file with sound settings. Pick SETUP, choose Sound Blaster at port 220, IRQ 7, DMA 1, then run the game.
  4. Change the speed. A game that is unplayably fast wants the 286 setting; one that crawls wants 486 or maximum.
  5. Choose “Just the C:\> prompt” and type the command yourself, the way the game's own README says to start it.

Where your files go

Nowhere. They are read with the browser's file API and written to an in-memory drive. No part of them is transmitted. Anything the program saves — saved games, high scores, settings — is kept in this browser and put back the next time you load the same program here.

The page uses Google Analytics for page metrics and Google AdSense for ads; neither can see your files or the emulator. Details in the privacy policy.

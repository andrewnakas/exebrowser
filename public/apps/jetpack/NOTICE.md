# Jetpack — freeware release

Adept Software (Adam Pedersen), 1993

## Why this is hosted here

Author released the complete 400-level registered version as freeware in December 1998; still hosted at adeptsoftware.com/jetpack.

## Source

Retrieved 2026-07-28 from DOS Games Archive: https://www.dosgamesarchive.com/download/jetpack

Only the original game files plus a `.jsdos/dosbox.conf` DOSBox configuration
are included. Modern additions from the source package (installers, icons,
PDFs, help launchers) were removed.

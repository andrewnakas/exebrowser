# 2048 — provenance

**Original work, written for ExeBrowser.** The HTML and JavaScript in this
directory were written from scratch for this site. No third-party code, no
decompiled binary, no extracted artwork.

Licensed **MIT**, the same as the rest of the ExeBrowser frontend.

## On the game

The original 2048 was written by Gabriele Cirulli in 2014 and released under
the MIT licence. **This implementation shares no code with it** — the rules are
simple enough to write directly, which keeps the provenance unambiguous. The
warm tile palette is the convention the genre settled on rather than a
trademark, and the game is named for its winning tile, which is a description
of the rules rather than a brand.

# One Must Fall: 2097 — freeware release

Diversions Entertainment / Epic MegaGames, 1994

## Why this is hosted here

Declared freeware by Diversions Entertainment in February 1999. The sequel (OMF: Battlegrounds) remains commercial and is not included.

## Source

Retrieved 2026-07-28 from DOS Games Archive: https://www.dosgamesarchive.com/download/one-must-fall-2097

Only the original game files plus a `.jsdos/dosbox.conf` DOSBox configuration
are included. Modern additions from the source package (installers, icons,
PDFs, help launchers) were removed.

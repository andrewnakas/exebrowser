# God of Thunder — freeware release

Ron Davis / Adept Software, 1993

## Why this is hosted here

Released as freeware by the author; source code released into the public domain March 2020. All three chapters included.

## Source

Retrieved 2026-07-28 from DOS Games Archive: https://www.dosgamesarchive.com/download/god-of-thunder

Only the original game files plus a `.jsdos/dosbox.conf` DOSBox configuration
are included. Modern additions from the source package (installers, icons,
PDFs, help launchers) were removed.

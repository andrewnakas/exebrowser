# Bio Menace — freeware release

Jim Norwood / Apogee Software, 1993

## Why this is hosted here

Released as freeware by 3D Realms in December 2005 as part of a batch of legacy Apogee titles.

## Source

Retrieved 2026-07-28 from DOS Games Archive: https://www.dosgamesarchive.com/download/bio-menace

Only the original game files plus a `.jsdos/dosbox.conf` DOSBox configuration
are included. Modern additions from the source package (installers, icons,
PDFs, help launchers) were removed.

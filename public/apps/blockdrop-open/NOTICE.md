# Block Drop — provenance

**Original work, written for ExeBrowser.** The HTML and JavaScript in this
directory were written from scratch for this site. No third-party code, no
decompiled binary, no extracted artwork.

Licensed **MIT**, the same as the rest of the ExeBrowser frontend.

## On the genre

Block Drop is a falling-block puzzle. The *rules* of such a game are not
copyrightable, and many independent implementations exist. But **"Tetris" is a
registered trademark**, actively enforced by The Tetris Company, and so are the
distinctive visual conventions associated with that product.

This game is therefore deliberately its own thing: its own name, its own code,
its own colours and its own presentation. It is not a clone of any particular
product, is not marketed as one, and no page on this site describes it as one.
We do not use the Tetris name anywhere, including in page titles, keywords or
metadata.

# Snake — provenance

**Original work, written for ExeBrowser.** The HTML and JavaScript in this
directory were written from scratch for this site. No third-party code, no
decompiled binary, no extracted artwork.

Licensed **MIT**, the same as the rest of the ExeBrowser frontend.

## On the game

Snake is not any single company's property. It descends from the 1976 arcade
game *Blockade*, and dozens of independent versions predate the one most people
remember from Nokia handsets in 1997. The rules are common property; this
implementation, its presentation and its monochrome-LCD styling are original.

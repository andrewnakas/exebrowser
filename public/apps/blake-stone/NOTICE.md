# Blake Stone: Aliens of Gold — shareware episode 1 (v3.0)

This package contains the freely-distributable **shareware episode** of Blake
Stone: Aliens of Gold (JAM Productions / Apogee Software, 1993), data version
3.0 dated 1994-11-01, with the original DOS executable `BS_AOG.EXE`.

Apogee's shareware distribution model explicitly permitted unmodified copies
of the shareware episode to be shared freely; the shareware episode has been
continuously distributed with the rights holder's blessing (it was hosted on
3D Realms' own legacy site as `1bs30.zip`).

Source: DOS Games Archive — https://www.dosgamesarchive.com/download/blake-stone-aliens-of-gold
(pre-installed "Blake Box" package, game files identical to the official
1bs30.zip installer contents; retrieved 2026-07-27).

The full game (six episodes) is still sold by the rights holder — see the
purchase links on the /run/blake-stone/ page. Modern additions from the
source package (icons, wrappers, help text) were removed; only original 1994
game files plus a DOSBox configuration are included.

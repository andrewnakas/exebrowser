# Alien Carnage (Halloween Harry) — freeware release

SubZero Software / Apogee Software, 1993

## Why this is hosted here

Released as freeware in May 2007 by Apogee jointly with original author John Passfield.

## Source

Retrieved 2026-07-28 from DOS Games Archive: https://www.dosgamesarchive.com/download/alien-carnage

Only the original game files plus a `.jsdos/dosbox.conf` DOSBox configuration
are included. Modern additions from the source package (installers, icons,
PDFs, help launchers) were removed.

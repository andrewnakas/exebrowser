# Xargon — freeware release

Allen Pilgrim / Epic MegaGames, 1993

## Why this is hosted here

Author released the full trilogy under an explicit written freeware licence in August 2008, along with the source code.

## Source

Retrieved 2026-07-28 from DOS Games Archive: https://www.dosgamesarchive.com/download/xargon

Only the original game files plus a `.jsdos/dosbox.conf` DOSBox configuration
are included. Modern additions from the source package (installers, icons,
PDFs, help launchers) were removed.

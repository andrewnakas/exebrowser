## Source

Retrieved 2026-11-13 from https://archive.org/download/ftp.3drealms.com/2016.01.27.ftp.3drealms.com.tar.xz
(file `ftp.3drealms.com/share/3dsw12.zip` inside that archive of Apogee / 3D Realms' own FTP server;
sha256 of both pinned in scripts/dos-sources.json).

The archive holds the publisher's installer. It was run inside DOSBox by
scripts/unpack-dos-installer.mjs, followed by the game's own sound setup program
(Sound Blaster defaults), and the bundle is exactly what it installed,
including the configuration file setup wrote, plus a
`.jsdos/dosbox.conf` DOSBox configuration.

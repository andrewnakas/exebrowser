# Dragon's Keep — original CC0 Phase 1 data package

This package contains original medieval-fantasy artwork, palette colors, text,
and synthesized audio created for the MIT-licensed SpaceCadetPinball engine.

For interoperability, it retains factual data measured from `DRAGON.DAT`:
container structure, group names and order, type codes, component positions,
sprite dimensions and functional masks, camera projection, collision geometry,
physics values, and sound filenames. It does not redistribute original bitmap,
palette, audio, music, or display-text expression.

Phase 1 intentionally uses the engine's existing Cadet rule implementation as
a placeholder. Faithful Dragon-specific missions and scoring belong to Phase 2.

Not affiliated with Microsoft, Maxis, or Cinematronics.

# SkyRoads — freeware release

Bluemoon Interactive, 1993

## Why this is hosted here

Released as freeware by Bluemoon Interactive; distributed at no charge ever since. Complete game, not a demo.

## Source

Retrieved 2026-07-28 from DOS Games Archive: https://www.dosgamesarchive.com/download/skyroads

Only the original game files plus a `.jsdos/dosbox.conf` DOSBox configuration
are included. Modern additions from the source package (installers, icons,
PDFs, help launchers) were removed.

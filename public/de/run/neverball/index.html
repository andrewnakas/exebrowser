So funktioniert es und was dich erwartet

Das Spiel ist der offizielle Build „Neverball in the browser“, nach WebAssembly kompiliert. Beim ersten Mal werden etwa 28 MB Spieldaten heruntergeladen, dann wird die Schaltfläche Play Now aktiv. Es braucht WebGL, das jeder aktuelle Browser hat, und läuft gut auf einem gewöhnlichen Laptop oder einem neueren Chromebook.

So wird gespielt

Bewege die Maus oder nimm die Pfeiltasten, um den Boden zu kippen. Linksklick und Rechtsklick drehen die Kamera. Auf einem Touchscreen wischst du zum Kippen und steuerst die Kamera mit dem zweiten Daumen; ein Gamepad funktioniert auch. Jedes Level zeigt an, wie viele Münzen das Ziel braucht; sammle so viele, und das Ziel öffnet sich. Wenn du über den Rand fällst, kostet dich das eine Kugel.

Fang mit dem Set Easy an. Die späteren Sets sind viel schwerer, als sie zunächst aussehen.

Häufige Fragen

Ist Neverball kostenlos?

Ja. Es ist freie Software unter der GNU GPL, und das ist das vollständige Spiel, keine Demo.

Läuft Neverball hier auch im Schul- oder Firmennetz?

Es wird nichts installiert: Das Spiel besteht aus Dateien, die von dieser Website kommen. Ob ein bestimmtes Schul- oder Firmennetz diese Website zulässt, entscheidet das jeweilige Netz. Das Addons-Menü des Spiels fragt die offizielle Neverball-Website nach der Liste der Add-ons; das Spiel läuft auch ohne sie.

Wird mein Fortschritt gespeichert?

Ja. Punktestände, freigeschaltete Level und Wiederholungen werden in diesem Browser gespeichert.

Kann ich auf dem Handy spielen?

Ja. Wische, um den Boden zu kippen. Ein größerer Bildschirm ist bequemer.

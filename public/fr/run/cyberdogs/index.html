Jouer à Cyberdogs en ligne — le jeu de tir freeware Fonctionne — le jeu freeware complet tourne via DOSBox dans votre navigateur

Guide mis à jour novembre 2026 · Fonctionne avec DOSBox + WebAssembly

Cyberdogs est le jeu de tir freeware en vue de dessus de Ronny Wester, sorti en 1994, celui dont C-Dogs est issu par la suite. Un ou deux joueurs sur le même clavier achètent des armes, puis se fraient un chemin à travers des missions où il faut récupérer ou détruire des objectifs. Le jeu complet est hébergé ici — cliquez sur jouer et il démarre dans votre navigateur.

GRATUIT C'est le jeu complet, gratuitement. Publié en freeware par son auteur, Ronny Wester : le jeu complet.

Fonctionne dans votre navigateur avec DOSBox et WebAssembly — rien n'est téléversé. Cliquez sur l'écran pour prendre la main ; appuyez sur Ctrl+F10 pour libérer la souris.

Cyberdogs est un freeware : son README indique “This game is freeware, feel free to spread it around.” (« Ce jeu est un freeware, n'hésitez pas à le diffuser. ») Provenance : /apps/cyberdogs/NOTICE.md.

Comment ça fonctionne et à quoi s'attendre

Le jeu DOS d'origine tourne dans une compilation WebAssembly de DOSBox. Il pèse environ 260 Ko et démarre en deux ou trois secondes. Il tourne à pleine vitesse sur n'importe quel appareil.

Comment y jouer

Choisissez un ou deux joueurs dans le menu, puis dépensez votre argent de départ à la boutique : une seconde arme et un peu de blindage changent beaucoup de choses. Dans chaque mission, remplissez les objectifs affichés au début, puis rejoignez la sortie. Les touches des deux joueurs sont affichées, et modifiables, dans les options du jeu.

Pourquoi c'est gratuit

Cyberdogs est un freeware. Le README de l'auteur l'affirme : “This game is freeware, feel free to spread it around.” (« Ce jeu est un freeware, n'hésitez pas à le diffuser. ») Les fichiers proposés ici sont ceux de la version d'origine, non modifiés.

Questions fréquentes

Cyberdogs est-il vraiment gratuit ?

Oui. Son auteur, Ronny Wester, l'a publié en freeware et invite chacun à le diffuser. C'est le jeu complet.

Peut-on jouer à deux ensemble ?

Oui, sur un seul clavier, en coopération. Les touches de chaque joueur se règlent dans le menu des options.

Quel est le lien avec C-Dogs ?

Cyberdogs est venu en premier. La suite de Wester, C-Dogs, est arrivée en 1997, et le projet open source C-Dogs SDL la prolonge aujourd'hui.

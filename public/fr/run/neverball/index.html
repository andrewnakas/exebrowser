Comment ça marche et à quoi s'attendre

Le jeu est la version officielle « Neverball in the browser », compilée en WebAssembly. Environ 28 Mo de données de jeu sont téléchargés la première fois, puis le bouton Play Now devient actif. Il lui faut WebGL, dont dispose tout navigateur actuel, et il tourne bien sur un ordinateur portable ordinaire ou un Chromebook récent.

Comment jouer

Bougez la souris, ou utilisez les touches fléchées, pour incliner le sol. Le clic gauche et le clic droit font pivoter la caméra. Sur un écran tactile, balayez pour incliner et servez-vous de l'autre pouce pour la caméra ; une manette fonctionne aussi. Chaque niveau indique combien de pièces l'arrivée exige ; ramassez-en autant et l'arrivée s'ouvre. Tomber du bord vous coûte une bille.

Commencez par la série Easy. Les séries suivantes sont bien plus difficiles qu'elles n'en ont l'air au premier abord.

Pourquoi c'est gratuit

Neverball est un logiciel libre sous GNU General Public License, version 2 ou ultérieure, développé ouvertement depuis 2003. C'est le jeu complet. Le code source complet de cette version est disponible sur ce site ; le fichier de notice explique où.

Questions fréquentes

Neverball est-il gratuit ?

Oui. C'est un logiciel libre sous GNU GPL, et c'est le jeu complet, pas une démo.

Neverball fonctionne-t-il ici sur un réseau d'école ou d'entreprise ?

Rien n'est installé : le jeu se résume à des fichiers servis depuis ce site. Qu'un réseau d'école ou d'entreprise donné autorise ou non ce site, cela dépend de ce réseau. Le menu Addons du jeu demande au site officiel de Neverball sa liste d'extensions ; le jeu fonctionne sans elle.

Ma progression est-elle sauvegardée ?

Oui. Les scores, les niveaux débloqués et les replays sont enregistrés dans ce navigateur.

Puis-je jouer sur téléphone ?

Oui. Balayez pour incliner le sol. Un écran plus grand est plus confortable.

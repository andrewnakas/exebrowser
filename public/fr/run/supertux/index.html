Jouer à SuperTux en ligne — le jeu complet, gratuit ▶ Jouer maintenant — version web officielle, s'ouvre en pleine page

Guide mis à jour novembre 2026 · Fonctionne avec WebAssembly (native port)

SuperTux est le jeu de plateforme à défilement horizontal, libre et open source, dont le héros est Tux le manchot : courez, sautez, écrasez des boules de neige et ramassez des pièces à travers l'Île Glacée (Icy Island) et la Forêt (Forest). Voici la version web officielle de la 0.6.3, réalisée par le projet SuperTux lui-même — le jeu complet. Cliquez sur le lanceur et il s'ouvre dans cet onglet.

Comment ça marche et à quoi s'attendre

Le jeu est la version WebAssembly officielle de l'équipe SuperTux, hébergée ici sans modification. Il est volumineux : environ 250 Mo de niveaux, de graphismes et de musique sont téléchargés la première fois que vous jouez ; lancez-le donc en Wi-Fi et laissez-lui une minute ou deux. Ensuite, votre navigateur le conserve.

SuperTux s'ouvre dans une page à part, et non à l'intérieur de celle-ci. Il fonctionne sur plusieurs threads, et les navigateurs ne l'autorisent que sur une page isolée des autres sites — ce que ne peut pas être un jeu intégré dans une autre page. Utilisez le bouton Précédent de votre navigateur pour revenir ici.

Il lui faut WebGL et un ordinateur raisonnablement récent. Il n'est pas adapté aux téléphones ni aux Chromebooks disposant de peu de mémoire.

Comment jouer

Utilisez les touches fléchées pour vous déplacer, Espace pour sauter et Ctrl pour courir ou lancer des boules de feu une fois que vous avez une fleur de feu ; la flèche bas permet de se baisser. Toutes les touches peuvent être modifiées dans Options → Setup Keyboard. Choisissez Start Game → Story Mode pour commencer sur Icy Island ; le Level Editor du menu principal fonctionne lui aussi dans le navigateur.

Pourquoi c'est gratuit

SuperTux est un logiciel libre. Son code est sous GNU General Public License, version 3 ou ultérieure, et la plupart de ses graphismes, niveaux et musiques sont sous Creative Commons Attribution-ShareAlike. Rien ici n'est une démo ni un premier épisode : c'est le jeu entier, tel que le projet l'a publié.

Questions fréquentes

Est-ce le SuperTux complet ?

Oui. C'est la version web officielle 0.6.3 publiée par le projet SuperTux, avec le Story Mode, les niveaux bonus et l'éditeur de niveaux.

Pourquoi le premier chargement est-il si long ?

Les données du jeu pèsent environ 250 Mo. Elles sont téléchargées une seule fois, puis conservées par votre navigateur ; les visites suivantes démarrent donc beaucoup plus vite.

Pourquoi s'ouvre-t-il dans une page séparée ?

SuperTux utilise plusieurs threads à la fois, et les navigateurs ne l'autorisent que sur une page isolée des autres sites. Un jeu intégré dans cette page ne pourrait pas être isolé ; le lanceur l'ouvre donc à part.

Ma progression est-elle sauvegardée ?

Oui. SuperTux enregistre vos sauvegardes dans ce navigateur. Effacer les données du site les supprime.

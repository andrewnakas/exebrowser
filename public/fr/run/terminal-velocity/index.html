Jouer à Terminal Velocity en ligne — l'épisode shareware Fonctionne — l'épisode shareware tourne via DOSBox dans votre navigateur

Guide mis à jour novembre 2026 · Fonctionne avec DOSBox + WebAssembly

Terminal Velocity est le jeu de tir aérien de Terminal Reality sorti en 1995 et édité par 3D Realms : pas de check-lists de simulateur de vol, juste un vaisseau rapide, des planètes ouvertes en 3D et des tunnels où plonger. L'épisode shareware officiel (version 1.2) est hébergé ici — cliquez sur jouer et il démarre dans votre navigateur.

Fonctionne dans votre navigateur avec DOSBox et WebAssembly — rien n'est téléversé. Cliquez sur l'écran pour prendre la main ; appuyez sur Ctrl+F10 pour libérer la souris.

Le shareware de Terminal Velocity est librement redistribuable en vertu du fichier LICENSE.TXT inclus dans le paquet. Le jeu enregistré est commercial et n'est pas hébergé ici. Provenance : /apps/terminal-velocity/NOTICE.md.

Comment ça fonctionne et à quoi s'attendre

La version shareware DOS d'origine tourne dans une compilation WebAssembly de DOSBox. Le paquet pèse moins de 4 Mo, et le son Sound Blaster est déjà configuré.

C'était une vitrine pour les PC rapides en 1995 : c'est donc l'un des jeux DOS les plus exigeants proposés ici. Il tourne bien sur un ordinateur portable ou de bureau récent.

Comment y jouer

Les touches fléchées pilotent le vaisseau. Le tir, la postcombustion et le choix des armes sont aussi au clavier ; l'écran d'aide du jeu (F1) en donne la liste, et elles peuvent être modifiées dans ses options. Abattez les cibles désignées sur chaque planète, puis trouvez l'entrée du tunnel : c'est dans les tunnels que se trouvent les boss.

La version shareware — et le jeu complet

Il s'agit de la version shareware, portant la mention « épisode un », dont 3D Realms a autorisé la diffusion gratuite dans le fichier LICENSE.TXT inclus dans le paquet. La licence indique clairement qu'elle ne couvre aucun autre épisode ; le jeu enregistré n'est pas hébergé ici.

Questions fréquentes

Est-ce légal de jouer à Terminal Velocity ici ?

Oui. Il s'agit de l'épisode shareware officiel, dont 3D Realms a autorisé la diffusion gratuite. Le jeu enregistré n'est pas hébergé.

Quelle partie du jeu est incluse ?

Le premier épisode du jeu : ses planètes et leurs sections en tunnel.

Puis-je piloter à la souris ?

Le clavier fonctionne d'emblée. Le pilotage à la souris peut être activé dans les options du jeu, mais le clavier est plus pratique dans un onglet de navigateur.

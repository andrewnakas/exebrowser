Jouer à Stargunner en ligne — l'épisode shareware Fonctionne — l'épisode shareware tourne via DOSBox dans votre navigateur

Guide mis à jour novembre 2026 · Fonctionne avec DOSBox + WebAssembly

Stargunner est le shoot'em up à défilement horizontal de 1996 qui fut l'un des derniers jeux publiés sous le nom d'Apogee : des vaisseaux précalculés, un défilement rapide et une boutique où les crédits achètent armes, moteurs et satellites. L'épisode shareware officiel (version 1.1) est hébergé ici — cliquez sur jouer et il démarre dans votre navigateur.

Fonctionne dans votre navigateur avec DOSBox et WebAssembly — rien n'est téléversé. Cliquez sur l'écran pour prendre la main ; appuyez sur Ctrl+F10 pour libérer la souris.

Le shareware de Stargunner est librement redistribuable en vertu du fichier LICENSE.DOC inclus dans le paquet. Le jeu enregistré est commercial et n'est pas hébergé ici. Provenance : /apps/stargunner/NOTICE.md.

Comment ça fonctionne et à quoi s'attendre

La version shareware DOS d'origine tourne dans une compilation WebAssembly de DOSBox. Le paquet pèse environ 5 Mo. Le jeu est fluide sur un ordinateur portable ordinaire.

Comment y jouer

Les touches fléchées déplacent le vaisseau. Les touches de tir sont indiquées dans les options de commandes du jeu, où elles peuvent être modifiées. Ramassez les crédits que lâchent les ennemis : après chaque niveau, vous pouvez les dépenser en armes avant, supérieures et inférieures, et en un moteur plus rapide. Un vaisseau équilibré s'en sort mieux qu'un seul canon énorme.

La version shareware — et le jeu complet

Il s'agit de l'épisode shareware, distribué en vertu du fichier LICENSE.DOC du paquet. Apogee a par la suite publié le jeu complet en freeware, sous la forme d'un installeur Windows ; la version hébergée ici est l'épisode shareware DOS, celui dont la licence autorise clairement la rediffusion.

Questions fréquentes

Oui. Il s'agit de l'épisode shareware officiel, dont Apogee autorise la diffusion gratuite dans son fichier LICENSE.DOC.

Le premier épisode du jeu, y compris la boutique entre les niveaux.

Jouer à 3D Pinball Space Cadet en ligne : gratuit, instantané, sans téléchargement Fonctionne · aucun fichier requis

Le flipper culte de Windows XP, jouable dès maintenant dans votre navigateur : sans téléchargement, sans installation et sans aucun fichier Microsoft Windows. Il s'agit d'une compilation WebAssembly du moteur open source SpaceCadetPinball, avec des ressources originales du domaine public. Fonctionne sous Windows 10, Windows 11, Mac, Linux et sur Chromebook. Cliquez sur Jouer : en quelques secondes, la bille est dans le lanceur.

Tout se passe dans votre navigateur : rien n'est envoyé, rien n'est installé. Cliquez sur le jeu pour qu'il capture le clavier. Lancer : maintenez puis relâchez Espace. Flippers : Z à gauche, / à droite. Nouvelle partie : F2. Souris : clic gauche = flipper gauche, clic droit = flipper droit. Échap libère la saisie. Les menus du jeu lui-même sont en anglais. Sur mobile, utilisez les boutons FLIP / LANCER sous la table.

Comment ça marche : du WebAssembly, pas de l'émulation

La plupart des sites qui proposent « Space Cadet en ligne » utilisent DOSBox ou un émulateur Windows pour faire tourner le binaire original de Microsoft, qui est un logiciel propriétaire. Cette version est différente : elle exécute le moteur open source SpaceCadetPinball, reconstitué par rétro-ingénierie à partir du binaire original par le développeur k4zmu2a, puis compilé en WebAssembly avec Emscripten. La physique, la détection des collisions, le comportement de la bille et la logique des missions sont fidèles aux originaux de 1995/2001.

Comme le moteur est compilé nativement en WebAssembly (et non enveloppé dans un émulateur), le jeu tourne à pleine vitesse dans n'importe quel navigateur récent — Chrome, Firefox, Edge, Safari — et sur n'importe quel système d'exploitation. Le bug de physique en 64 bits n'existe pas non plus ici : le portage open source a corrigé le problème d'arrondi en virgule flottante qui avait poussé Microsoft à retirer le jeu à partir de Windows Vista.

Fonctionne partout où Windows XP ne va pas

  • Windows 10 et 11 : le jeu original a disparu avec Vista ; cette version fonctionne sur tous les Windows récents.
  • Mac et Linux : aucun besoin de Windows.

  • Débloqué à l'école : du WebAssembly pur dans le navigateur ; aucun téléchargement, plugin ou installation à bloquer.

Missions : les 9 types de missions

Space Cadet compte 9 catégories de missions. Chacune s'active en touchant dans l'ordre les trois voyants jaunes Mission (en haut de la table), puis en remplissant un objectif. Les missions rapportent des promotions et des points bonus. Les noms anglais d'origine, entre parenthèses, sont ceux affichés dans le jeu.

  1. Entraînement au lancement (Launch Training) — touchez dans l'ordre les bumpers de lancement
  2. Menace extraterrestre (Alien Menace) — détruisez les cibles extraterrestres de la rampe droite
  3. Peste cosmique (Cosmic Plague) — touchez le trou noir et les bumpers dans l'ordre
  4. Citation (Commendation) — réussissez trois skill shots dans la même partie
  5. Mayday — gardez la bille en jeu dans le puits gravitationnel
  6. Mission secrète (Secret Mission) — trouvez la cible cachée sur le côté gauche
  7. Reconnaissance (Recon) — allumez tous les voyants jaunes autour de la table
  8. Stase (Stasis) — utilisez la séquence multibille de la rampe droite
  9. Sauvetage (Rescue) — il faut d'abord terminer toutes les autres missions

Accomplir des missions vous fait monter en grade. Les grades supérieurs débloquent des missions plus difficiles, avec de meilleurs multiplicateurs de score.

Progression des grades : de Cadet à Amiral de la flotte

Astuces et stratégie

  • Maîtrisez le skill shot : relâchez le lanceur exactement au bon moment pour toucher le voyant jaune du haut dès le lancement ; cela allume gratuitement le premier voyant Mission.
  • Servez-vous du puits gravitationnel : le trou noir au centre fait passer la bille par des séquences multibille si vous le touchez pendant qu'il clignote.
  • Secouez la table avec prudence : le jeu gère le tilt (même si la sensibilité de cette version peut varier) ; de légères secousses aident à guider la bille sans déclencher le tilt.
  • Priorité aux drapeaux : les quatre cibles drapeaux du côté droit donnent un multiplicateur de score de 2× quand elles sont toutes allumées. Rallumez-les chaque fois que la table se réinitialise.
  • Protégez l'écoulement : le couloir extérieur gauche est l'endroit où l'on perd le plus de billes. Sur une bille lente, gardez toujours le flipper gauche prêt.
  • Montez vite en grade : enchaîner Entraînement au lancement → Menace extraterrestre → Peste cosmique dans cet ordre donne les promotions les plus rapides en début de partie et de plus gros bonus de points.

Histoire : de Full Tilt! Pinball à Windows XP

Space Cadet était à l'origine l'une des trois tables de Full Tilt! Pinball (1995), un jeu commercial développé par Cinematronics et édité par Maxis (le studio de SimCity). Microsoft n'a acheté la licence que de la table Space Cadet et l'a intégrée au Plus! Pack de Windows 95, avant de l'inclure gratuitement dans Windows XP, où des millions de personnes en ont fait leur pause préférée au bureau.

Quand Microsoft a conçu Windows Vista en 64 bits, le moteur physique de Space Cadet a cessé de fonctionner correctement. La bille traversait les flippers, car le code d'origine effectuait des calculs en virgule flottante dont les résultats différaient légèrement entre processeurs 64 bits et 32 bits. Plutôt que de réécrire la physique, Microsoft a retiré le jeu à partir de Vista. Raymond Chen, chez Microsoft, en a documenté la cause technique exacte sur son blog de développeur en janvier 2022.

Le jeu est resté pratiquement introuvable pour toute une génération d'utilisateurs de Windows, jusqu'en 2021, quand le développeur k4zmu2a a rétro-ingénieré le binaire original de Windows XP et publié SpaceCadetPinball en open source. Le moteur décompilé corrige le bug de physique en 64 bits, ce qui le rend même plus précis que l'original sur du matériel moderne. Cette version pour navigateur s'appuie sur ce moteur.

Questions fréquentes

Faut-il des fichiers de Microsoft Windows pour jouer ?

Non. Cette version utilise des ressources entièrement open source et ne demande aucun fichier de Windows XP, de Windows 95 ni d'aucun produit Microsoft. Cliquez simplement sur Jouer et le jeu se charge instantanément dans votre navigateur : rien à fournir, rien à télécharger.

Est-ce que ça fonctionne sous Windows 10 et Windows 11 ?

Oui. Comme le jeu tourne dans votre navigateur grâce à WebAssembly, il fonctionne sous Windows 10, Windows 11, macOS, Linux et sur Chromebook : sur n'importe quel appareil doté d'un navigateur récent comme Chrome, Firefox, Edge ou Safari. Microsoft a retiré le jeu original après Windows XP ; cette version open source pour navigateur n'a pas cette limite.

Pourquoi 3D Pinball Space Cadet a-t-il disparu de Windows ?

Microsoft a abandonné Space Cadet lors du développement de Windows Vista 64 bits. Le moteur physique souffrait d'un bug d'arrondi en virgule flottante : sur les processeurs 64 bits, certains calculs décimaux donnaient des résultats légèrement différents de ceux des processeurs 32 bits, si bien que la bille traversait parfois les flippers et les murs. Plutôt que de réécrire la physique, Microsoft a supprimé le jeu. Raymond Chen, chez Microsoft, en a documenté la cause exacte sur son blog de développeur en janvier 2022. Le moteur open source SpaceCadetPinball utilisé ici corrige ce bug.

Est-ce le vrai Space Cadet de Microsoft ?

Cette version utilise le moteur open source issu de la rétro-ingénierie (sous licence MIT), avec des graphismes et des sons originaux placés dans le domaine public (CC0), et non le binaire propriétaire de Microsoft. Les règles physiques, les missions et la jouabilité sont fidèles à l'original, mais aucun fichier Microsoft n'est utilisé ni inclus. Peut-on jouer à Space Cadet Pinball débloqué à l'école ?

Oui. Le jeu tourne entièrement dans votre navigateur grâce à WebAssembly : pas de téléchargement, pas de plugin, pas d'installation. Il fonctionne sur les Chromebook scolaires et sur les réseaux qui bloquent le téléchargement de jeux ou les contenus Flash/Java. Ouvrez simplement cette page et cliquez sur Jouer.

Est-ce que ça marche sur mobile ou tablette ?

Oui. Les commandes tactiles sont intégrées : touchez la partie gauche de la table pour le flipper gauche, la partie droite pour le flipper droit, et le bouton central sous la table pour lancer la bille. Sur les petits écrans, la table s'agrandit pour occuper tout l'écran quand vous appuyez sur Jouer.

Quelles sont les missions de Space Cadet Pinball ?

Il existe 9 types de missions : Entraînement au lancement (Launch Training), Menace extraterrestre (Alien Menace), Peste cosmique (Cosmic Plague), Citation (Commendation), Mayday, Mission secrète (Secret Mission), Reconnaissance (Recon), Stase (Stasis) et Sauvetage (Rescue). Chacune s'active en allumant dans l'ordre les trois voyants jaunes Mission. Accomplir des missions vous fait monter en grade, de Cadet (Cadet) jusqu'à Amiral de la flotte (Fleet Admiral).

La touche du flipper droit ne marche pas : que faire ?

Par défaut, le flipper droit est associé à la touche / (barre oblique). Sur un clavier AZERTY ou d'autres dispositions non QWERTY, cette touche peut ne pas être reconnue correctement. Utilisez le clic droit comme flipper droit de remplacement : il fonctionne quelle que soit la disposition de votre clavier.

Comment ça fonctionne et à quoi s'attendre

La version shareware DOS d'origine tourne dans une compilation WebAssembly de DOSBox. Elle pèse moins de 200 Ko et se charge instantanément. C'est un jeu EGA 16 couleurs, qui tourne à pleine vitesse sur n'importe quel appareil.

Comment y jouer

Les flèches déplacent l'agent, Ctrl fait sauter et Alt tire. Les munitions sont limitées : ne tirez donc pas sur tout ce qui bouge. Dans chaque base, il faut trouver la disquette et l'apporter à l'ordinateur pour couper les lasers, puis utiliser la dynamite sur la porte de sortie. Les lunettes à ramasser révèlent les plateformes cachées.

La version shareware — et le jeu complet

Il s'agit du premier épisode sur trois, la version shareware. Le fichier VENDOR.DOC d'Apogee, inclus dans le paquet, encourage à le diffuser gratuitement. Les épisodes deux et trois constituent le jeu enregistré et ne sont pas hébergés ici.

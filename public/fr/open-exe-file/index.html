Comment ouvrir un fichier EXE

Un fichier .exe est un programme Windows : l'ouvrir, c'est l'exécuter. Ce qu'il faut pour cela dépend de l'ordinateur que vous utilisez :

  • Sous Windows : double-cliquez dessus. S'il ne démarre pas, le message d'erreur indique généralement la cause — les plus courantes sont détaillées plus bas.
  • Sur Mac ou sous Linux : utilisez Wine ou CrossOver, une machine virtuelle Windows, ou exécutez-le dans un onglet du navigateur.
  • Sur un Chromebook, ou sur un ordinateur où vous ne pouvez rien installer : exécutez-le dans un onglet du navigateur. Rien à installer, et le fichier ne quitte jamais votre machine.

Ouvrir un .exe dans le navigateur

Ce qu'est réellement un fichier .exe

Un .exe est un programme compilé pour Windows. Ni un document, ni une archive, ni une vidéo : un ensemble d'instructions machine, accompagné d'un en-tête qui indique à Windows comment les charger. C'est pourquoi « Ouvrir avec » ne fonctionne jamais sur un tel fichier : il n'existe pas de visionneuse pour un programme, puisque le programme est l'application.

Cela explique aussi les deux situations dans lesquelles on arrive généralement ici. Soit vous êtes sur un Mac, sous Linux ou sur un Chromebook, où les programmes Windows ne fonctionnent tout simplement pas ; soit vous êtes sous Windows et le fichier refuse de démarrer pour l'une d'une poignée de raisons bien précises. Ce sont deux problèmes différents, avec des réponses différentes.

Le plus rapide à essayer

Ce site exécute des programmes Windows dans un onglet du navigateur. Déposez un .exe sur la page du lanceur et il tentera de l'exécuter localement — le fichier est lu sur votre propre machine et n'est jamais envoyé nulle part.

Soyons honnêtes sur les limites, car elles sont réelles : cela fonctionne le mieux avec les logiciels Windows 32 bits d'environ 1995 à 2008. Les petits utilitaires et les jeux anciens sont le terrain idéal. Tout ce qui exige un .NET moderne, un vrai accès réseau ou un contexte graphique 3D ne fonctionnera pas, et nous documentons les échecs aux côtés des réussites plutôt que de prétendre le contraire.

Ouvrir un .exe sur chaque plateforme

Sur Mac

macOS ne peut pas exécuter nativement les fichiers .exe : c'est un autre système d'exploitation et, depuis Apple Silicon, une autre architecture de processeur. Un double-clic produit une erreur, et aucun « Ouvrir avec » n'y changera rien.

Les vraies options sont une couche de compatibilité comme Wine ou CrossOver, qui traduit les appels à l'API Windows au lieu d'émuler un PC ; une machine virtuelle faisant tourner une copie de Windows sous licence ; ou, pour les petits programmes anciens, l'exécution ici, dans un onglet du navigateur. La voie du navigateur ne demande aucune installation, ce qui est souvent l'argument décisif.

Sur Chromebook

ChromeOS ne peut absolument pas installer de logiciels Windows, et c'est un choix de conception, pas un oubli. Il n'y a pas de Wine à installer, pas de dossier Program Files, nulle part où un installateur pourrait s'installer.

Il reste donc l'exécution dans le navigateur, ce que fait ce site, ou le conteneur Linux si votre Chromebook l'a activé et que vous êtes à l'aise pour y installer Wine. Il existe un article plus long sur les quatre approches, classées selon les efforts que chacune demande.

Sous Linux

Installez Wine depuis le gestionnaire de paquets de votre distribution, puis lancez wine votreprogramme.exe. Wine est mûr et une grande partie des logiciels fonctionne du premier coup. Quand il échoue, il échoue généralement bruyamment, en nommant la DLL ou l'API qu'il n'a pas pu fournir, ce qui vous donne au moins une piste de recherche.

Sous Windows, quand il ne démarre pas

Si c'est Windows lui-même qui refuse d'exécuter un programme Windows, la liste des causes probables est courte et le message d'erreur indique généralement laquelle est en jeu :

  • « Cette application ne peut pas s'exécuter sur votre PC ». Le plus souvent, un programme 16 bits. Windows 64 bits a supprimé le sous-système qui les exécutait, et aucun réglage ne le fait revenir.
  • Une DLL manquante est nommée. Une bonne nouvelle, toutes proportions gardées : le programme a besoin d'un runtime que vous n'avez pas. En général le redistribuable Visual C++, le runtime Visual Basic 6 ou le .NET Framework 3.5.
  • SmartScreen le bloque. Windows ne reconnaît pas l'éditeur. Si vous êtes sûr de la provenance du fichier, cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».
  • Il ne se passe rien du tout. Souvent un programme en console qui s'est ouvert, exécuté et refermé plus vite que vous ne pouviez le voir. Essayez de le lancer depuis l'invite de commandes pour que la fenêtre reste ouverte.

Chacun de ces cas est expliqué plus en détail dans pourquoi les anciens programmes ne démarrent pas sous Windows 11.

Quand vous ne voulez pas du tout l'exécuter

Parfois, le but n'est pas d'exécuter le programme mais d'accéder à ce qu'il contient. Les installateurs, en particulier, ne sont généralement que des archives dans un emballage, et un grand nombre d'anciennes applications sont portables une fois décompressées : un simple dossier qui fonctionne sans jamais toucher au registre.

Notre extracteur d'archives ouvre les fichiers .exe auto-extractibles ainsi que les 7z, ZIP, RAR et les autres, entièrement dans le navigateur et sans rien envoyer. Le guide complet couvre les cas qu'il ne sait pas traiter et ce qu'il faut utiliser à la place.

Si vous voulez seulement savoir ce qu'est le fichier, la visionneuse EXE lit ses en-têtes et vous montre le processeur pour lequel il a été compilé, les bibliothèques système qu'il charge, son icône et s'il est signé — sans en exécuter la moindre partie.

Et si vous hésitez à l'exécuter tout court, ce .exe est-il sûr ? passe en revue toutes les vérifications utiles et ce que chacune prouve réellement.

Avant d'exécuter quoi que ce soit

Un .exe de provenance inconnue peut faire tout ce que votre compte utilisateur peut faire. Ce n'est pas de l'alarmisme, c'est simplement la nature d'un programme. Deux précautions valent la peine : vérifier le fichier sur VirusTotal, et préférer le téléchargement de l'éditeur d'origine à celui d'un agrégateur qui l'a emballé dans son propre installateur.

L'exécuter dans un onglet du navigateur est nettement plus sûr que de l'exécuter nativement, car le bac à sable du navigateur est une vraie frontière et le programme n'a aucun accès à votre véritable système de fichiers. Ce n'est pas un permis d'exécuter des logiciels malveillants, mais c'est une façon raisonnable d'examiner quelque chose dont vous n'êtes pas sûr.

Plus sûr encore : ne pas l'exécuter. Lire les en-têtes du fichier ne coûte rien et répond à la plupart des questions courantes : est-ce la bonne architecture, est-ce un installateur plutôt que le programme, un éditeur est-il nommé, le fichier est-il signé, est-il compressé de façon à ne rien révéler avant de s'exécuter.

Questions fréquentes

Qu'est-ce qu'un fichier .exe ?

Un programme compilé pour Windows : des instructions machine et un en-tête qui indique à Windows comment les charger. Ce n'est pas un document, il n'y a donc rien « avec » quoi l'ouvrir : on l'exécute. Ce qu'il y a à l'intérieur va plus loin.

Qu'est-ce qu'une application exe ?

La même chose : « application exe » désigne généralement une application Windows distribuée sous forme de .exe, soit le programme lui-même, soit un installateur qui le copie sur votre ordinateur. Les téléphones et les Mac ne peuvent pas l'exécuter nativement.

Puis-je ouvrir un fichier .exe en ligne sans rien télécharger ?

Vous pouvez en exécuter un ici sans rien installer, ce qui est le sens habituel de la question. Le fichier est lu par votre navigateur sur votre propre machine : il n'est pas envoyé sur un serveur. Ce sont les petits programmes Windows 32 bits qui fonctionnent le mieux.

Comment ouvrir un .exe sur Mac ?

Pas nativement. Utilisez Wine ou CrossOver, une machine virtuelle Windows, ou exécutez-le dans un onglet du navigateur. Pour les programmes anciens et légers, le navigateur est de loin la solution la moins contraignante.

Pourquoi rien ne se passe quand je double-clique ?

En général, c'est un programme en console qui s'est ouvert et refermé aussitôt, ou un runtime manquant qui échoue en silence. Lancez-le depuis l'invite de commandes pour voir l'erreur au lieu de la deviner.

Est-il sûr d'ouvrir un fichier .exe ?

Il n'est sûr qu'autant que sa provenance. Un programme peut faire tout ce que votre compte peut faire. Vérifiez-le sur VirusTotal, préférez le téléchargement de l'éditeur lui-même et, en cas de doute, l'exécuter dans le bac à sable d'un navigateur est bien plus sûr que de l'exécuter nativement.

Et s'il est en 64 bits ?

Le runtime d'ici est en 32 bits : les programmes uniquement 64 bits ne se chargeront pas. Beaucoup d'applications antérieures à 2010 environ existaient aussi en version 32 bits, et celle-ci fonctionne généralement.

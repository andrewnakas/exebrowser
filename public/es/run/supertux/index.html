Guía actualizada en noviembre de 2026 · Funciona con WebAssembly (native port)

SuperTux es el juego de plataformas de desplazamiento lateral, libre y de código abierto, protagonizado por el pingüino Tux: corre, salta, aplasta bolas de nieve y recoge monedas por la Isla Helada (Icy Island) y el Bosque (Forest). Esta es la versión web oficial de la 0.6.3, obra del propio proyecto SuperTux: el juego completo. Haz clic en el lanzador y se abrirá en esta pestaña.

Cómo funciona y qué esperar

El juego es la versión WebAssembly oficial del equipo de SuperTux, alojada aquí sin cambios. Es grande: la primera vez que juegas se descargan unos 250 MB de niveles, gráficos y música, así que ábrelo con Wi-Fi y dale un minuto o dos. Después, tu navegador lo conserva.

SuperTux se abre como una página propia, no dentro de esta. Funciona con varios hilos, y los navegadores solo lo permiten en una página aislada de otros sitios, algo que no puede ser un juego enmarcado dentro de otra página. Usa el botón Atrás del navegador para volver aquí.

Necesita WebGL y un ordenador razonablemente reciente. No es una buena opción para móviles ni para Chromebooks con poca memoria.

Cómo jugar

Usa las flechas para moverte, Space para saltar y Ctrl para correr o lanzar bolas de fuego cuando tengas una flor de fuego; con la flecha abajo te agachas. Todas las teclas se pueden cambiar en Options → Setup Keyboard. Elige Start Game → Story Mode para empezar en Icy Island; el Level Editor del menú principal también funciona en el navegador.

Por qué es gratis

SuperTux es software libre. Su código está bajo la GNU General Public License, versión 3 o posterior, y la mayor parte de sus gráficos, niveles y música está bajo Creative Commons Attribution-ShareAlike. Aquí nada es una demo ni un primer episodio: es el juego entero, tal como lo publicó el proyecto.

Preguntas frecuentes

¿Es este el SuperTux completo?

Sí. Es la versión web oficial 0.6.3 publicada por el proyecto SuperTux, con Story Mode, los niveles extra y el editor de niveles.

¿Por qué tarda tanto en cargar la primera vez?

Los datos del juego ocupan unos 250 MB. Se descargan una sola vez y después tu navegador los conserva, así que las visitas siguientes arrancan mucho más rápido.

¿Por qué se abre como una página aparte?

SuperTux usa varios hilos a la vez, y los navegadores solo lo permiten en una página aislada de otros sitios. Un juego enmarcado dentro de esta página no podría estar aislado, así que el lanzador lo abre por separado.

¿Se guarda mi progreso?

Sí. SuperTux guarda tus partidas en este navegador. Si borras los datos del sitio, se eliminan.

Jogue Freedoom no seu navegador Funciona bem — jogo livre e completo via DOSBox

Guia atualizado em julho de 2026 · Roda com DOSBox + WebAssembly

Freedoom é um substituto totalmente livre para os arquivos de dados do DOOM: mesma jogabilidade, mas com fases, gráficos e sons criados do zero pela comunidade e distribuídos sob uma licença livre. Não há nenhum conteúdo proprietário envolvido.

Isso faz dele o único jogo desta lista sem nenhuma ressalva de licença — não é shareware, não é um episódio de demonstração, é o jogo inteiro e você pode copiá-lo à vontade. Roda no navegador com o motor DOS clássico via DOSBox.

O lançamento oficial e livre

Os dados de jogo do Freedoom são publicados sob uma licença BSD modificada — você pode copiar, modificar e redistribuir à vontade, desde que a licença e os créditos acompanhem o material. Pegue a versão oficial no próprio projeto:

Baixar o Freedoom (site oficial) →

O download traz freedoom1.wad (Phase 1, no estilo do Ultimate Doom) e freedoom2.wad (Phase 2, no estilo do Doom II). São arquivos de dados WAD, não um executável — você também precisa de um motor DOOM. A combinação gratuita mais simples é um pequeno port Win32 com renderização por software, como o Chocolate Doom ou o Crispy Doom. Coloque o .EXE do port e um freedoomN.wad na mesma pasta e rode no seu computador — nada disso é necessário aqui, já que esta página inicia o Freedoom para você. Tudo o que está envolvido, jogo e motor, é genuinamente livre e de código aberto.

O que ele é e o que não é

O Freedoom não é o DOOM da id Software com outro nome. É um conjunto de fases e recursos originais, feito para rodar no mesmo motor, com o objetivo de existir um jogo completo no estilo DOOM que seja inteiramente livre.

Quem conhece o original vai reconhecer o ritmo e a lógica das armas, mas as fases são novas. Como jogo, ele se sustenta sozinho.

Controles

Setas para andar, Ctrl para atirar, Espaço para abrir portas e 1 a 7 para trocar de arma. O mouse funciona para mirar. Em celulares aparece um teclado na tela.

Perguntas frequentes

O Freedoom é a mesma coisa que o DOOM?

Não. Ele usa o mesmo motor, mas todas as fases, gráficos e sons foram criados do zero e são distribuídos sob licença livre. Nenhum arquivo original da id Software está envolvido.

É realmente livre e legal?

É. Os dados do Freedoom são publicados sob uma licença BSD modificada que permite explicitamente a redistribuição gratuita, então podemos hospedá-lo sem nenhuma ressalva.

O meu progresso fica salvo?

Fica. Além do sistema de salvar do jogo, se você fechar a aba no meio de uma fase o site oferece retomar de onde parou. Tudo permanece no seu navegador.

Jogue Neverball online — grátis, no seu navegador ▶ Jogue agora — versão web oficial, roda aqui mesmo

Guia atualizado em novembro de 2026 · Roda com WebAssembly (native port)

Neverball é o jogo de código aberto em que você não move a bola — você inclina o chão embaixo dela. Role por cada pista em 3D, colete moedas suficientes para abrir a meta e chegue lá antes que o tempo acabe. Esta é a versão web oficial do próprio projeto Neverball. Como funciona e o que esperar

O jogo é a versão oficial “Neverball in the browser”, compilada para WebAssembly. Cerca de 28 MB de dados do jogo são baixados na primeira vez, e então o botão Play Now fica ativo. Ele precisa de WebGL, que todo navegador atual tem, e roda bem num notebook comum ou num Chromebook recente.

Como jogar

Mova o mouse, ou use as setas, para inclinar o chão. O clique esquerdo e o clique direito giram a câmera. Numa tela de toque, deslize o dedo para inclinar e use o outro polegar para a câmera; um controle também funciona. Cada fase mostra quantas moedas a meta exige; colete essa quantidade e a meta se abre. Cair pela borda custa uma bola.

Comece pelo conjunto Easy. Os conjuntos seguintes são muito mais difíceis do que parecem à primeira vista.

Por que é grátis

Neverball é software livre sob a GNU General Public License, versão 2 ou posterior, e é desenvolvido abertamente desde 2003. Este é o jogo completo. O código-fonte completo desta versão está disponível neste site; o arquivo de aviso explica onde.

Perguntas frequentes

Neverball é grátis?

É. É software livre sob a GNU GPL, e este é o jogo completo, não uma demo.

O Neverball funciona aqui na rede da escola ou do escritório?

Nada é instalado: o jogo são arquivos servidos por este site. Se uma determinada rede de escola ou de escritório permite este site, isso depende dessa rede. O menu Addons do jogo pede a lista de complementos ao site oficial do Neverball; o jogo funciona sem ela.

Meu progresso fica salvo?

Sim. Pontuações, fases desbloqueadas e replays ficam guardados neste navegador.

Dá para jogar no celular?

Dá. Deslize o dedo para inclinar o chão. Uma tela maior é mais confortável.

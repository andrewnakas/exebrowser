SuperTux é o jogo de plataforma de rolagem lateral, livre e de código aberto, estrelado pelo pinguim Tux: corra, pule, esmague bolas de neve e colete moedas pela Ilha Gelada (Icy Island) e pela Floresta (Forest). Esta é a versão web oficial da 0.6.3, feita pelo próprio projeto SuperTux — o jogo completo. Clique no iniciador e ele abre nesta aba.

Como funciona e o que esperar

O jogo é a versão WebAssembly oficial da equipe do SuperTux, hospedada aqui sem alterações. Ele é grande: cerca de 250 MB de fases, gráficos e música são baixados na primeira vez que você joga, então comece no Wi-Fi e dê um ou dois minutos. Depois disso, seu navegador guarda tudo.

O SuperTux abre como uma página própria, não dentro desta. Ele roda em várias threads, e os navegadores só permitem isso numa página isolada de outros sites — o que um jogo incorporado dentro de outra página não consegue ser. Use o botão Voltar do navegador para retornar aqui.

Ele precisa de WebGL e de um computador razoavelmente recente. Não é uma boa opção para celulares nem para Chromebooks com pouca memória.

Como jogar

Use as setas para se mover, Space para pular e Ctrl para correr ou atirar bolas de fogo quando tiver uma flor de fogo; a seta para baixo faz você se abaixar. Todas as teclas podem ser trocadas em Options → Setup Keyboard. Escolha Start Game → Story Mode para começar em Icy Island; o Level Editor do menu principal também funciona no navegador.

Por que é grátis

SuperTux é software livre. O código está sob a GNU General Public License, versão 3 ou posterior, e a maior parte da arte, das fases e da música está sob a Creative Commons Attribution-ShareAlike. Nada aqui é demo ou primeiro episódio: é o jogo inteiro, como o projeto o lançou.

Perguntas frequentes

Este é o SuperTux completo?

Sim. É a versão web oficial 0.6.3 publicada pelo projeto SuperTux, com o Story Mode, as fases bônus e o editor de fases.

Por que demora tanto para carregar na primeira vez?

Os dados do jogo têm cerca de 250 MB. Eles são baixados uma única vez e depois ficam guardados no seu navegador, então as próximas visitas começam bem mais rápido.

Por que ele abre como uma página separada?

O SuperTux usa várias threads ao mesmo tempo, e os navegadores só permitem isso numa página isolada de outros sites. Um jogo incorporado dentro desta página não poderia ser isolado, então o iniciador o abre separadamente.

Meu progresso fica salvo?

Sim. O SuperTux guarda seus jogos salvos neste navegador. Limpar os dados do site apaga esses saves.

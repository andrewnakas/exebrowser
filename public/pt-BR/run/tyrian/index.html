Jogue Tyrian 2000 no seu navegador Funciona — freeware completo rodando via DOSBox

Guia atualizado em julho de 2026 · Roda com DOSBox + WebAssembly

Tyrian 2000 é um shoot 'em up de rolagem vertical de 1995, e provavelmente o mais bonito jogo do gênero feito para DOS. Os próprios autores o liberaram como freeware, então não é uma versão de demonstração: é o jogo inteiro, com todos os episódios.

Roda aqui através do DOSBox compilado para WebAssembly, ou seja, é o executável DOS original. Sem baixar, sem instalar, sem conta.

Por que este é diferente dos outros

Por que este é diferente dos outros

Boa parte dos jogos clássicos disponíveis de graça são episódios shareware — a primeira parte de graça e o resto vendido. O Tyrian não é assim. Os detentores dos direitos liberaram o jogo completo como freeware, então o que você joga aqui é tudo o que existe.

Vale a pena mexer na loja entre as fases: o sistema de melhorias da nave é o coração do jogo, e guardar créditos sem gastar costuma ser um erro.

Controles

Use as setas para pilotar, Espaço para o disparo secundário e Enter para confirmar nos menus. O mouse também funciona para mirar. Em celulares aparece um teclado na tela.

Perguntas frequentes

O jogo é completo mesmo ou só uma demonstração?

É completo. Os autores liberaram o Tyrian 2000 inteiro como freeware, com todos os episódios — não há uma versão paga escondida atrás disso.

É legal jogar aqui?

É. O jogo foi liberado como freeware pelos próprios detentores dos direitos, com permissão de distribuição gratuita.

O meu progresso fica salvo?

Fica. Além do sistema de salvar do próprio jogo, se você fechar a aba no meio de uma fase o site oferece retomar exatamente de onde parou. Tudo fica no seu navegador e nada é enviado para servidor nenhum.

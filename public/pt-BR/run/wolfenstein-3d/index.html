Jogue Wolfenstein 3D online no seu navegador Funciona — o jogo DOS original roda via DOSBox no navegador

Guia atualizado em julho de 2026 · Roda com DOSBox + WebAssembly

Wolfenstein 3D — o avô dos jogos de tiro em primeira pessoa, lançado pela id Software e pela Apogee em 1992 — e o seu primeiro episódio shareware é gratuito e legal de jogar. O ExeBrowser roda jogos DOS diretamente via DOSBox compilado para WebAssembly, então este é o binário DOS de verdade, não um remake nem uma reimplementação em JavaScript.

Sem baixar nada, sem instalar nada, sem criar conta. Clique em jogar e o episódio um começa em segundos — e o seu progresso fica salvo no navegador.

Baixe o shareware do Wolfenstein 3D (grátis e legal)

O episódio shareware (arquivos de dados) e um source port Win32

Você precisa de duas peças, ambas gratuitas e legais:

  1. Os dados do shareware — o primeiro episódio, de livre redistribuição (os arquivos *.WL1). A Apogee lançou o episódio um como shareware para ser copiado sem custo, e o Internet Archive mantém cópias preservadas.
  2. Um source port Win32 — uma reconstrução moderna e de código aberto do motor, que roda como um EXE de Windows. ECWolf (pegue a build de 32 bits) ou o mais enxuto Wolf4SDL.

Para jogar no seu computador, coloque o EXE do source port e todos os arquivos *.WL1 em uma única pasta. Aqui nada disso é necessário: esta página já inicia o episódio shareware. © id Software / Apogee. Apenas o episódio shareware é de livre redistribuição; os episódios registrados, as Nocturnal Missions e o Spear of Destiny são comerciais — compre na id / Steam.

Como funciona e o que esperar

O que roda aqui é o executável DOS original de 1992 dentro do DOSBox, compilado para WebAssembly. Isso significa que a jogabilidade, os gráficos e o som são exatamente os que saíram no disquete — nada foi remasterizado ou reinterpretado.

O episódio um, Escape from Wolfenstein, tem dez fases e é o que a id Software liberou para distribuição gratuita. Os outros cinco episódios foram vendidos e continuam sendo comerciais, então não estão aqui.

Controles e desempenho

Use as setas para andar, Ctrl para atirar, Espaço para abrir portas e as teclas de 1 a 5 para trocar de arma. Em celulares e tablets aparece um teclado na tela com os controles do jogo.

O jogo é de 1992 e pesa pouco, então roda bem até em máquinas modestas e em Chromebooks — o navegador faz todo o trabalho e nada é enviado para servidor nenhum.

Perguntas frequentes

Dá para jogar Wolfenstein 3D de graça sem baixar?

Sim. O episódio um é shareware que a id Software liberou para distribuição gratuita, e ele roda direto no navegador. Não há nada para instalar e não é preciso criar conta.

Este é o Wolfenstein 3D de verdade ou um remake?

É o jogo original. O executável DOS de 1992 roda dentro do DOSBox compilado para WebAssembly, então é o mesmo código que rodava num PC da época.

É legal jogar aqui?

É. Só hospedamos o primeiro episódio, que foi distribuído como shareware justamente para ser copiado e repassado livremente. Os episódios comerciais não estão aqui.

O meu progresso fica salvo?

Fica, e não só pelo menu de salvar do próprio jogo. Se você fechar a aba no meio de uma fase, na próxima visita o site oferece voltar exatamente de onde parou. Tudo fica no seu navegador — nada é enviado para lugar nenhum e não existe conta.

Funciona no celular?

Funciona. Aparece um teclado na tela com os controles do jogo. A experiência é melhor no computador, mas dá para jogar no celular sem problema.

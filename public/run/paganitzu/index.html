How it works & what to expect

The original DOS shareware release runs inside a WebAssembly build of DOSBox. It is about 260 KB and loads at once. Press Enter at the opening screens. It is a 16-colour EGA game and runs at full speed on any device.

Playing it

The game first asks three setup questions (graphics, controller, sound): press 1 for each. The arrow keys then move Alabama one square at a time. Collect all the keys in a room to open the exit. Boulders can be pushed but not pulled, so think before you shove one into a corner. If you trap yourself, the game has a key to restart the room; its instructions list it.

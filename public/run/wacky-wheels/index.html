How it works & what to expect

The original DOS shareware release running in a WebAssembly build of DOSBox. The package is about 1.5 MB. The pseudo-3D track scaling is the heaviest thing it does, and a laptop or desktop keeps up easily.

Controls

The arrow keys steer; the driving and firing keys are listed, and can be changed, in the game's options. Collect the hedgehogs on the track to have something to throw.

Shareware version — and the full game

This is the shareware release Apogee distributed under its VENDOR.DOC, which permits sharing it and forbids distributing the registered game. The full game is still sold.

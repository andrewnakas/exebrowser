Freeciv is a free, open-source empire-building strategy game inspired by Civilization — and there is an excellent browser version, Freeciv-web, that needs no download at all.

Runs in your browser tab with WebAssembly + Wine — nothing is uploaded. Click the screen to capture input; press Esc to release the mouse.

How it works & what to expect

How to start a single-player game

Open Freeciv-web, type any player name when prompted (creating an account is optional — it's only needed to save games), then press START in the toolbar. SETUP lets you change the ruleset, map size and number of AI opponents first.

What Freeciv is

Freeciv began in 1996 as an open-source take on Civilization and is still actively developed. You build cities, research technologies, negotiate or fight with AI nations, and try to win by conquest, space race or score. The web client runs the same rulesets as the desktop game, including a Civ2-style "Classic+" default.

Prefer something that plays right here?

If you want strategy without leaving this tab, Scorched Earth is a turn-based artillery game hosted here, and Hearts is a trick-taking card game with three AI opponents. Both start instantly.

Frequently asked questions

Why can't I start a game on this page any more?

We removed the embed because it was broken. Browsers block third-party storage inside frames, so Freeciv-web couldn't create a session and showed a "please enter a name to join the game" prompt instead of starting a single-player match. On its own site it works correctly, so we link there.

Is Freeciv free?

Yes — it's open source under the GPL, and Freeciv-web is free to play in any modern browser with no account required. An account is only needed if you want to save games.

Do I need to download anything?

No. Freeciv-web runs entirely in the browser. The desktop version is a separate download if you prefer a native client.

How do I pick a nation or change the map?

Use SETUP before pressing START to choose the ruleset, map size, and how many AI players you face. NATION lets you pick your civilisation.

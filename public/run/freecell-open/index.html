How to play FreeCell

All 52 cards are dealt face-up into eight columns. The goal is the same as Solitaire — build all four foundations up by suit from ace to king — but nothing is hidden, so every deal is a puzzle rather than a gamble.

The four free cells

Each free cell holds exactly one card. They're your working space: park a card that's in the way, use the column beneath it, then bring it back. Running out of free cells is how most games are lost, so spend them deliberately.

Building

Columns build down in alternating colours, like Solitaire. Any card may fill an empty column — not just a king — which makes empty columns enormously valuable.

Supermoves

Strictly, you can only move one card at a time. In practice, moving a run of n cards is just a sequence of single moves through your free cells, so the game does it for you. The limit is (free cells + 1) × 2empty columns — which is why freeing a column suddenly doubles what you can shift.

Strategy that actually helps

  • Empty a column early. An empty column is worth more than a free cell — it doubles your supermove size and takes any card.
  • Find the aces. Look at where the aces are buried before your first move. Digging them out is usually the whole plan.
  • Don't fill every free cell. With all four occupied you can only move one card, and the game is effectively over.
  • Plan backwards from the deep cards. The card at the bottom of the worst column determines what you have to achieve; work out how to reach it first.
  • Undo freely. FreeCell is a puzzle, not a test of nerve. Trying a line and reversing it is the intended way to play.

Frequently asked questions

Is this Microsoft FreeCell?

No. Microsoft's freecell.exe is proprietary Windows software and we can't legally host it. This is an original implementation of the same game, written for ExeBrowser and free to play. It reproduces the Microsoft deal numbering, so a deal number means the same layout here as it does in Windows. For the Microsoft build itself, see our FreeCell guide.

Are the deal numbers the same as Windows?

Yes. The deal is generated by the same documented algorithm the Windows games used, so deal #1 here is the deal #1 you remember, and the famously unsolvable #11982 is unsolvable here too.

Is every FreeCell game winnable?

Almost. Of the original 32,000 Microsoft deals, all but one are solvable — #11982 is the single proven exception. That is a far higher rate than any other common solitaire, which is why FreeCell rewards thinking rather than luck.

What is a supermove?

Moving several cards at once. Officially you move one card at a time, but a run can be relayed through your free cells and empty columns, so the game performs that sequence for you. The number you can move is (free cells + 1) doubled for each empty column.

Do I need to download or sign up for anything?

No. The game runs directly in your browser as plain JavaScript — no emulator, no download, no account, and nothing is uploaded. It starts instantly and works on phones as well as desktops.

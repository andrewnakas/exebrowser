How it works & what to expect

The original DOS shareware release runs inside a WebAssembly build of DOSBox. The package is under 3 MB and starts in a few seconds. The game asks for a pilot name first; type anything and press Enter.

Descent was a demanding game in 1995 and it still asks more of the emulator than a 2D title. A laptop or desktop from the last several years plays it smoothly.

Playing it

Your ship moves on six axes, which takes a few minutes to get used to. With the default keyboard layout A and Z thrust forward and back, the arrow keys turn and pitch, Ctrl fires lasers and Space fires missiles. Tab opens the 3D automap, which you will need. Each level ends the same way: destroy the reactor, then find the exit before the mine blows.

All keys can be remapped under Options → Customize.

Shareware version — and the full game

The game's own README says it best: “This game may be freely distributed.” That applies to this shareware version with its seven levels. The registered game has 30 levels and is not hosted here.

Frequently asked questions

Is it legal to play Descent here?

Yes. This is the shareware version, whose README states that it may be freely distributed. The registered 30-level game is not hosted.

How many levels are included?

Seven: the complete shareware release, version 1.4.

Can I use a mouse or joystick?

The keyboard works out of the box and is how most people played the shareware. Mouse control can be switched on in the game's Options menu, but a browser tab does not pass a joystick through to DOS.

Does my progress save?

Yes, best-effort. Your pilot and saved games are kept in this browser and restored on the next visit.

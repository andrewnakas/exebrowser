Frequently asked questions

Is Tyrian 2000 really free to play?

Yes. Rights holder Jason Emery released the full game as freeware in 2004, the graphics were later placed under an open-content license, and it's given away free on GOG as well. There's nothing to buy and nothing shady about playing it.

Can I play Tyrian 2000 unblocked at school or work?

Generally yes, though it is the heaviest game here: about 4.8 MB, because Tyrian 2000 is freeware in full and all five episodes ship with it. On a slow shared connection the first load takes a moment, after which it is cached. It runs entirely inside the tab under DOSBox, with no installer and no admin rights needed. A network filter blocking the domain is the one thing that defeats it.

Can I play Tyrian 2000 in the browser with no download?

Yes. Press play and the complete game boots to its title screen in a few seconds. Because Tyrian 2000 is freeware, its data ships with the page — there is nothing to find, upload or install.

Is this the real Tyrian or a remake?

The real one. The original DOS executable and its original data run unmodified inside DOSBox compiled to WebAssembly, so it's the same game that shipped on the disks — not a re-creation and not a source port.

How many episodes do I get?

All five. Tyrian 2000 was released as freeware in full, so unlike the shareware games on this site there is no episode held back behind a purchase.

What is OpenTyrian2000?

A free, open-source (GPL) rebuild of the game as a modern native executable, using the same freeware data files. It's the best way to play Tyrian on a desktop — it's SDL-based and aimed at a real machine rather than this browser sandbox, which is why this page runs the original DOS build instead.

Will it run at full speed?

Usually, yes. An x86 CPU is emulated inside WebAssembly, but Tyrian is a 1995 DOS game and light enough that a modern laptop handles it comfortably. Expect some slowdown on older tablets and Chromebooks.

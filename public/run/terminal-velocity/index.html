How it works & what to expect

The original DOS shareware release runs inside a WebAssembly build of DOSBox. The package is under 4 MB, with Sound Blaster sound already configured.

This was a showpiece for fast PCs in 1995, so it is one of the more demanding DOS games here. It plays well on a recent laptop or desktop.

Playing it

The arrow keys fly the ship. Firing, afterburner and weapon selection are on the keyboard too; the game's help screen (F1) lists them, and they can be changed in its options. Shoot the marked targets on each planet, then find the tunnel entrance: the tunnels are where the bosses are.

Shareware version — and the full game

How it works & what to expect

The game is the SuperTux team's official WebAssembly release, hosted here unchanged. It is big: about 250 MB of levels, graphics and music are downloaded the first time you play, so start it on Wi-Fi and give it a minute or two. After that your browser keeps it.

SuperTux opens as a page of its own, not inside this one. It runs on several threads, and browsers only allow that on a page that is isolated from other sites — which a game framed inside another page cannot be. Use your browser's Back button to return here.

It needs WebGL and a reasonably recent computer. It is not a good fit for phones or for low-memory Chromebooks.

Playing it

Use the arrow keys to move, Space to jump and Ctrl to run or throw fireballs once you have a fire flower; the down arrow ducks. Every key can be changed under Options → Setup Keyboard. Choose Start Game → Story Mode to begin on Icy Island; the Level Editor on the main menu works in the browser too.

Why it is free

SuperTux is free software. Its code is under the GNU General Public License, version 3 or later, and most of its artwork, levels and music are under Creative Commons Attribution-ShareAlike. Nothing here is a demo or a first episode: it is the whole game, as the project released it.

Frequently asked questions

Is this the full SuperTux?

Yes. It is the official 0.6.3 web build published by the SuperTux project, with Story Mode, the bonus levels and the level editor.

Why does it take so long to load the first time?

The game's data is about 250 MB. It is downloaded once and then kept by your browser, so later visits start much faster.

Why does it open as a separate page?

SuperTux uses several threads at once, and browsers only allow that on a page isolated from other sites. A game framed inside this page could not be isolated, so the launcher opens it on its own.

Does my progress save?

Yes. SuperTux stores your save games in this browser. Clearing the site's data removes them.

How it works & what to expect

How it runs here

OMF is a DOS game, not a Windows one — it needs a DOS4GW protected-mode extender that Wine alone can't provide. That's why it needs DOSBox rather than the Wine runtime, and why this page once said it couldn't run. Our DOS games now boot in a WebAssembly build of DOSBox, which handles the extender natively. It's our largest payload at about 6 MB, so the first boot takes a few seconds; after that it's cached.

About the game

Eleven pilots, ten upgradeable HAR mechs, and a tournament mode where prize money buys stat upgrades between fights — that progression is what people still remember it for, along with a soundtrack players hunt down to this day. Specials use quarter-circle and charge motions, and everything is rebindable in the in-game setup menu.

Want it on your own machine?

The freeware release is still distributed openly, and OpenOMF is an open-source re-implementation of the engine that runs natively on modern systems using the same original data files. Both are worth a look if you want it outside a browser tab; neither is needed to play here.

Frequently asked questions

Can I play One Must Fall 2097 in the browser with no download?

Yes. Play it here — it boots in about a second via DOSBox compiled to WebAssembly. Nothing to install and nothing is uploaded.

Is One Must Fall 2097 really free?

Yes. Diversions Entertainment declared it freeware in February 1999, so the complete game is legal to play, share and host. The sequel, One Must Fall: Battlegrounds, is a separate commercial release.

Why did this page used to say it wouldn't run?

Because it wouldn't, at the time. OMF is a DOS program and ExeBrowser originally ran only Win32 software through Wine. We've since added a DOSBox runtime for DOS games, so the old workarounds — DOSBox-in-Wine, or a source port — are no longer needed.

What are the controls?

Arrows move and jump; Ctrl, Alt and Space attack. Specials use quarter-circle and charge motions. The in-game Setup menu rebinds everything, and the play page lists the full control table under the game.

What is OpenOMF?

An open-source re-implementation of the OMF 2097 engine that runs natively on modern systems using the original freeware data files. Useful if you want the game outside a browser; not required to play it here.

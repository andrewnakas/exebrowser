Play Dragon's Keep pinball — free, instant, no download Works · no files needed

Dragon's Keep is an original medieval-fantasy pinball table you can play right now in your browser — no download, no install, no Windows files required. It runs on the open-source SpaceCadetPinball engine compiled to WebAssembly, with all-new CC0 (public domain) castle-and-dragon artwork, palette, and synthesized audio built for this release.

Temporarily offline. The Phase 1 build crashes on load — its WebAssembly module hits a memory fault before the table renders. Rather than leave a black screen behind a Play button, we've taken it down until the build is fixed.

In the meantime, Open Cadet runs the same engine with a complete, working table — full missions and ranks, free and instant.

Runs entirely in your browser — nothing uploaded, nothing installed. Click the game to capture input. Launch: hold & release Space. Flippers: Z left, / right. New game: F2. Mouse: left-click = left flipper, right-click = right flipper. Esc releases input. On mobile use the FLIP / LAUNCH buttons below the table.

What Dragon's Keep is — and what it isn't

Full Tilt! Pinball (1995, Cinematronics/Maxis) shipped three tables: Space Cadet — which Microsoft bundled with Windows — plus two tables most people never got to play, Skulduggery and Dragon's Keep. The original Dragon's Keep data remains proprietary, so it can't legally be hosted anywhere.

This version is an independent open-source recreation: the table geometry, collision physics, and component positions are retained as factual measurements (facts aren't copyrightable), while every bitmap, palette, sound effect, and text string is wholly original work released to the public domain (CC0). The result is the first Dragon's Keep-style table that anyone can host, share, or modify freely.

Phase 1 status: the visuals and audio are complete; missions and scoring currently reuse the engine's Cadet rule implementation. Phase 2 will bring table-specific missions. If you want the fully mission-faithful experience today, play Open Cadet — same engine, complete ruleset.

Frequently asked questions

Do I need any Windows or Full Tilt files to play?

No. All artwork, audio, and text in this build are original CC0 public-domain works on the MIT-licensed open-source engine. Nothing proprietary is included or required.

Is this the real Full Tilt! Dragon's Keep table?

No — it's an independent recreation inspired by it. Table layout and physics are factual measurements; all creative assets are new. In Phase 1 the missions and scoring still follow the classic Cadet ruleset.

Can I play it on mobile or Chromebook?

Yes. It runs in any modern browser via WebAssembly, with built-in touch controls — tap left/right for flippers and use the LAUNCH button to fire the plunger.

Is it really free? What's the license?

Yes. The engine is MIT-licensed and the entire data package (art, sounds, text) is CC0 — public domain. You can play, copy, host, or modify it without asking anyone.

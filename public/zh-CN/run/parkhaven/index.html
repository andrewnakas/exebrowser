这是什么游戏

Parkhaven 是一款主题乐园模拟游戏。每位走进大门的游客都有自己的预算、胃口、膀胱，以及对自己能承受多刺激的设施的判断。他们沿着你铺的路闲逛、挑选设施、排队、花钱买吃的和纪念品、乱扔垃圾、迷路，还会告诉你他们的想法。让他们开心，乐园评分就会上升，进而吸引更多游客走进大门。

游戏的核心是过山车编辑器。轨道一节一节地铺设，列车按简单的物理规律运行，试运行会测量最高速度、G 力、落差、腾空时间和翻转次数。这些数据会换算成设施的刺激度、强度和眩晕度评分，决定谁愿意坐、愿意付多少钱。除此之外还有平地游乐设施、卡丁车、激流勇进、小卖部、清洁工、机修工、保安和表演人员，以及故障与检修、天气、研发和市场营销。

乐园起步指南

  • 先修路，从大门开始。游客只能到达有道路相连的地方。每个设施的入口和出口都必须接上道路。
  • 先从温和的开始。旋转木马和旋转咖啡杯几乎人人都能玩。大型设施留到以后，等你买得起、游客也受得了的时候再建。
  • 让游客吃饱，并把厕所建在吃的旁边。又饿又渴、还找不到厕所的游客会不高兴地离开。
  • 尽早雇清洁工。道路上的垃圾和呕吐物拉低乐园评分的速度比什么都快。
  • 开放前先试运行。强度太高的过山车没人坐。弯道缓一点、落差低一点能降低强度；加个回环能提升刺激度。
  • 按价值定价。设施窗口会显示游客认为它值多少钱。定价略低于这个数就好。

常见问题

这是《过山车大亨》（RollerCoaster Tycoon）吗？

不是。Parkhaven 是专门为本站从零编写的原创游戏，和 RollerCoaster Tycoon（1999）这类主题乐园模拟游戏属于同一类型。它不含任何来自该游戏或 OpenRCT2 的代码、美术、音效或文字，与 Chris Sawyer、Atari 和 Frontier 均无关联。它依据一份描述该类型玩法的书面说明开发，与原版游戏完全隔离。详见来源声明（英文）。

需要下载什么吗？

不需要。Parkhaven 是直接在网页中运行的纯 JavaScript 和 WebGL 程序，没有模拟器，也不需要你提供任何游戏文件。只需要一个支持 WebGL 2 的浏览器，而目前所有电脑和手机浏览器都支持。

怎么建造过山车？

打开 Rides，选择 Steel Coaster（钢制过山车），放好车站。之后编辑器会一节一节地添加轨道：直道、坡道、弯道、提升坡、刹车段和回环。让轨道绕回车站，进行一次试运行，把入口和出口接到道路上，然后开放。试运行会测量速度、G 力、落差和腾空时间，这些数据决定设施的刺激度、强度和眩晕度。

可以保存我的乐园吗？

可以。游戏每过一个游戏月会自动存档，菜单里还有三个存档位。存档保存在这台设备的这个浏览器里。

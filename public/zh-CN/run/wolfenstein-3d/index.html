获取 Wolfenstein 3D 共享软件版（免费且合法）

共享软件章节（数据文件）加一个 Win32 源码移植版

你需要两样东西，都是免费且合法的：

  1. 共享软件的数据——可自由再分发的第一章（那一组 *.WL1 文件）。Apogee 当年把第一章作为共享软件发布，允许免费复制，Internet Archive 保存有副本。
  2. 一个 Win32 源码移植版——用开源方式重写的引擎，以 Windows EXE 的形式运行。可以用 ECWolf（请选32 位版本），或者更精简的 Wolf4SDL。

它是怎么跑起来的

这个页面运行的是16 位的 DOS 原版——1992 年那个真正的 WOLF3D.EXE——把它放在编译成 WebAssembly 的 DOSBox 里执行。没有套两层模拟，也没有重新实现：就是当年发行的共享软件章节，几秒钟就能启动。

你玩到的是货真价实的那一款：B.J. Blazkowicz、迷宫般的地堡、推开暗墙找密室，以及那种一眼就能认出的光线投射画面。声音也是当年 AdLib 和 PC 扬声器的输出，所以听起来是 1992 年的样子，而不是现代移植版重新渲染的效果。以今天的标准看，Wolfenstein 3D 轻得几乎不占分量，任何一台当代机器都能满速运行；只有相当老旧的 Chromebook 和平板才可能感到吃力。

如果你想在自己电脑上装一个源码移植版

id 在 1995 年开源了 Wolfenstein 3D 的引擎，社区据此做出了现代的重写版本——ECWolf 和 Wolf4SDL——它们读取的正是同一批共享软件 .WL1 数据，但支持更高分辨率、鼠标视角和现代显示器。装在电脑上很值得。

不过它们是桌面程序。这个页面刻意运行的是当年的 DOS 版本，因为那一版完全不需要你做任何准备。

常见问题

不下载任何东西就能免费玩吗？

可以。Apogee 和 id 在 1992 年把第一章作为共享软件发布，明确允许免费复制，此后它一直被自由分发。这个页面就是在浏览器里运行那个共享软件章节，不用下载、不用安装，也不需要账号。

在这里玩合法吗？

就共享软件版的第一章而言，合法。注册版章节、Nocturnal Missions 和 Spear of Destiny 属于商业产品，这里并不提供——那些请到 id 或 Steam 购买。

这是真正的 Wolfenstein 3D 还是重制版？

是真的那一款。1992 年的 DOS 可执行文件和当年的数据未经改动，直接在 DOSBox 里运行。它不是粉丝重做，也不是源码移植版，就是当年发行的那个游戏。

操作方式是什么？

先点一下游戏画面，把键盘交给它。方向键或 WASD 移动，Ctrl 开火，Space 开门和推暗墙，数字键 1 到 4 切换武器，Esc 打开菜单。

为什么有时候会卡？

x86 处理器是在 WebAssembly 里模拟出来的，速度大约是原生的 10% 到 40%。Wolfenstein 3D 足够轻，这个速度在任何一台较新的笔记本上都绰绰有余；很老的平板和 Chromebook 可能会显得迟钝。

进度会保存吗？

会，而且不只是靠游戏自带的存档菜单。你在关卡中途关掉标签页，下次再来时页面会问你要不要从原地继续，因为整个模拟器状态都被快照保存在浏览器的存储里。什么都不会上传，也没有账号——存档就留在你玩的那台设备上，换一台电脑就带不过去了。

这里运行的是真正的 DOS 可执行文件，既不是重制版，也不是用 JavaScript 重写的复刻。我们把 DOSBox 编译成了 WebAssembly，让原始程序直接在浏览器里跑起来。无需下载，无需安装，也不用注册账号。

它是怎么运行的

它是怎么运行的

在浏览器里运行的是 1993 年发行的那个 DOS 可执行文件，外面套了一层编译成 WebAssembly 的 DOSBox。画面、声音和手感都和当年软盘里的一模一样，没有做过任何重制。

收录的是第一章，共九个关卡，正是 id Software 允许自由再分发的部分。其余章节属于商业版本，这里没有提供。

操作方式和运行要求

方向键移动，Ctrl 开火，Space 开门，1 到 7 切换武器，也支持用鼠标转向。在手机和平板上，屏幕会显示一组虚拟按键。

这是 1993 年的游戏，体积很小，即使在 Chromebook 这样配置一般的设备上也能流畅运行。所有计算都在浏览器里完成，不会向服务器发送任何数据。

常见问题

不下载就能免费玩吗？

可以。第一章是 id Software 发布的共享软件版本，允许免费传播，直接在浏览器里就能运行。没有任何需要安装的东西，也不用注册。

这是真正的 DOOM 还是重制版？

是真正的原版。1993 年的 DOS 可执行文件在编译成 WebAssembly 的 DOSBox 里运行，和当年在 PC 上跑的是同一份代码。

在这里玩合法吗？

合法。我们只提供第一章，它当初就是作为共享软件发布的，本来就允许自由复制和转发。商业章节没有收录。

游戏进度会保存吗？

会。除了游戏自带的存档功能，即使你在关卡中途关掉标签页，下次打开时也可以从中断的地方继续。所有数据都保存在你自己的浏览器里，不会上传到任何地方；因为没有账号，所以也不会同步到其他设备。

手机上能玩吗？

能。在触屏设备上，屏幕会显示一组游戏用的虚拟按键。用电脑玩体验更好，但手机上完全可以玩。

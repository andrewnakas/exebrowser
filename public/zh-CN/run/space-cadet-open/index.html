Windows XP 的经典弹球游戏，现在就能在浏览器里玩——无需下载，无需安装，也不需要任何微软 Windows 文件。这是开源 SpaceCadetPinball 引擎的 WebAssembly 版本，搭配原创的公有领域素材。Windows 10、Windows 11、Mac、Linux 和 Chromebook 都能运行。点击开始，几秒钟后弹球就已经在发射杆上等着你了。

工作原理——WebAssembly，而不是模拟器

大多数提供“在线玩 Space Cadet”的网站，都是用 DOSBox 或 Windows 模拟器来运行微软的原版程序——而那是专有软件。这个版本不一样：它运行的是开源的 SpaceCadetPinball 引擎，由开发者 k4zmu2a 对原版程序进行逆向工程重建，再通过 Emscripten 编译成 WebAssembly。物理效果、碰撞检测、弹球运动和任务逻辑都忠实于 1995 年和 2001 年的原版。

因为引擎是直接编译成 WebAssembly 的（而不是套在模拟器里），游戏在任何现代浏览器——Chrome、Firefox、Edge、Safari——和任何操作系统上都能全速运行。这里也不存在 64 位物理错误：开源移植版修复了当年导致微软从 Windows Vista 起移除这款游戏的浮点舍入问题。

SpaceCadetPinball 引擎采用 MIT 许可证。这个版本使用的球台数据文件（PINBALL.DAT）、全部美术和全部音效，都是以 CC0（公有领域）发布的原创作品——从零开始制作，并非源自微软的素材。这不是微软游戏的盗版，而是一部受其启发、可以自由再分发的独立作品。

任务——全部 9 类任务

Space Cadet 共有 9 类任务。依次击中球台顶部的三个黄色任务（Mission）灯即可激活任务，然后完成对应目标。完成任务可以晋升军衔并获得额外分数。括号里是游戏中显示的英文原名。

  1. 发射训练（Launch Training）——按顺序击中发射区的弹射器
  2. 外星威胁（Alien Menace）——摧毁右侧坡道上的外星目标
  3. 宇宙瘟疫（Cosmic Plague）——按顺序击中黑洞和弹射器
  4. 嘉奖（Commendation）——在一局中完成三次技巧射击
  5. 紧急求救（Mayday）——让弹球在重力井中保持不落
  6. 秘密任务（Secret Mission）——找到左侧隐藏的目标
  7. 侦察（Recon）——点亮球台周围所有黄色指示灯
  8. 停滞（Stasis）——利用右侧坡道的多球序列
  9. 营救（Rescue）——需要先完成其他所有任务

完成任务会获得军衔晋升。军衔越高，解锁的任务越难，分数倍率也越高。

军衔系统是 Space Cadet 最有特色的设计之一。你从学员起步，通过完成任务和累积分数不断晋升。以下是全部 9 个军衔：

技巧与策略

  • 练好技巧射击：在恰当的时机松开发射杆，让弹球在发射时击中顶部的黄灯——这样可以免费点亮第一盏任务灯。
  • 利用重力井：中间的黑洞在闪烁时被击中，会让弹球进入多球序列。
  • 小心推台：游戏支持倾斜（Tilt）判定（不过这个版本的倾斜灵敏度可能不太稳定）——轻轻推一下可以引导弹球，又不会触发倾斜。
  • 优先点亮旗帜：右侧的四个旗帜目标全部点亮后，分数倍率变为 2×。每次球台重置后都要重新点亮。
  • 守住出球口：左侧外通道是最常见的漏球位置。球速慢的时候，左挡板要随时准备好。
  • 快速升衔：按“发射训练 → 外星威胁 → 宇宙瘟疫”的顺序完成任务，前期升衔最快，分数奖励也更多。

历史——从 Full Tilt! Pinball 到 Windows XP

Space Cadet 最初是 Full Tilt! Pinball（1995）中的三张球台之一。这是一款商业游戏，由 Cinematronics 开发、Maxis（就是做《模拟城市》的那家公司）发行。微软只授权了 Space Cadet 这一张球台，先把它放进 Windows 95 的 Plus! 扩展包，后来又免费内置到 Windows XP 中——数以百万计的人在工作间隙玩过它，对它念念不忘。

微软把 Windows Vista 做成 64 位系统时，Space Cadet 的物理引擎出了问题。弹球会直接穿过挡板，因为原版代码中的浮点运算在 64 位和 32 位处理器上会得出略有差异的结果。微软没有重写物理代码，而是从 Vista 起把这款游戏砍掉了。微软的 Raymond Chen 在 2022 年 1 月的开发者博客中记录了确切的技术原因。

此后整整一代 Windows 用户几乎都玩不到这款游戏——直到 2021 年，开发者 k4zmu2a 对 Windows XP 的原版程序进行了逆向工程，并以开源项目的形式发布了 SpaceCadetPinball。反编译出的引擎修复了 64 位物理错误，因此在现代硬件上甚至比原版更精确。这个浏览器版本就是基于该引擎构建的。

常见问题

玩这个游戏需要微软 Windows 的文件吗？

不需要。这个版本使用的全部是开源资源，不需要 Windows XP、Windows 95 或任何微软产品里的文件。点一下“开始游戏”，游戏就会立刻在浏览器里加载——不用提供任何文件，也不用下载任何东西。

Windows 10 和 Windows 11 上能玩吗？

能。它通过 WebAssembly 在浏览器里运行，所以 Windows 10、Windows 11、macOS、Linux 和 Chromebook 都能玩——只要设备上有 Chrome、Firefox、Edge 或 Safari 这类现代浏览器就行。原版游戏在 Windows XP 之后被微软移除了，而这个开源的浏览器版本没有这个限制。

为什么 Windows 里没有三维弹球了？

微软在开发 64 位 Windows Vista 时放弃了 Space Cadet。它的物理引擎有一个浮点舍入错误：在 64 位处理器上，某些小数运算的结果和 32 位处理器略有不同，导致弹球偶尔会直接穿过挡板和墙壁。微软没有选择重写物理代码，而是干脆把游戏砍掉了。微软的 Raymond Chen 在 2022 年 1 月的开发者博客中记录了具体原因。这里使用的开源 SpaceCadetPinball 引擎已经修复了这个错误。

这是微软正版的 Space Cadet 吗？

这里用的是通过逆向工程重建的开源引擎（MIT 许可证），配合原创的 CC0 公有领域美术和音效，而不是微软的专有程序。物理规则、任务和玩法都忠实于原版，但没有使用或包含任何微软文件。如果你想运行真正的原版程序，请看我们的《通过 Wine 运行 3D Pinball Space Cadet》指南（英文页面，需要你自己提供游戏副本）。

在学校能玩不被屏蔽的三维弹球吗？

能。它完全通过 WebAssembly 在浏览器里运行——不用下载，不用插件，也不用安装。在学校的 Chromebook 上，以及屏蔽游戏下载或 Flash/Java 内容的网络中都能玩。打开这个页面，点“开始游戏”就行。

手机或平板上能玩吗？

能。游戏内置了触屏操作：点球台左侧控制左挡板，点右侧控制右挡板，点球台下方的中间按钮发射。在小屏幕上，点“开始游戏”后球台会放大并铺满整个屏幕。

Space Cadet 弹球有哪些任务？

一共有 9 类任务：发射训练（Launch Training）、外星威胁（Alien Menace）、宇宙瘟疫（Cosmic Plague）、嘉奖（Commendation）、紧急求救（Mayday）、秘密任务（Secret Mission）、侦察（Recon）、停滞（Stasis）和营救（Rescue）。依次点亮三个黄色的任务指示灯即可激活任务。完成任务可以晋升军衔，从学员（Cadet）一路升到舰队司令（Fleet Admiral）。

右挡板的按键没反应，怎么办？

右挡板默认绑定在 /（斜杠）键上。在非 QWERTY 布局或某些其他语言的键盘上，这个键可能无法正确识别。可以改用鼠标右键来控制右挡板——无论键盘布局如何都能用。

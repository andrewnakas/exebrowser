运行方式与注意事项

这个游戏是 SuperTux 团队的官方 WebAssembly 版本，原样托管在这里。它体积很大：第一次玩时要下载约 250 MB 的关卡、图像和音乐，所以请在 Wi-Fi 下启动，并给它一两分钟。之后浏览器会把它保留下来。

SuperTux 会作为一个独立的页面打开，而不是嵌在本页里。它使用多个线程运行，而浏览器只允许与其他网站隔离的页面这样做——嵌在另一个页面里的游戏做不到这一点。用浏览器的“后退”按钮就能回到这里。

它需要 WebGL 和一台比较新的电脑，不太适合手机或内存较小的 Chromebook。

怎么玩

用方向键移动，Space 跳跃，Ctrl 奔跑，拿到火焰花之后还能用它扔火球；下方向键是蹲下。所有按键都可以在 Options → Setup Keyboard 里修改。选择 Start Game → Story Mode，从 Icy Island 开始；主菜单里的 Level Editor 在浏览器里同样可用。

常见问题

这是完整版的 SuperTux 吗？

是的。这是 SuperTux 项目发布的 0.6.3 官方网页版，包含 Story Mode、奖励关卡和关卡编辑器。

为什么第一次加载这么慢？

游戏数据约有 250 MB。它只需下载一次，之后由浏览器保留，所以以后再来启动会快得多。

为什么它要在单独的页面里打开？

SuperTux 会同时使用多个线程，而浏览器只允许与其他网站隔离的页面这样做。嵌在本页里的游戏无法被隔离，所以启动器会把它单独打开。

我的进度会保存吗？

会。SuperTux 把你的存档保存在这个浏览器里。清除本站数据会把存档删掉。
